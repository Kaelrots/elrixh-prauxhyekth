# r_1_통합_아키텍처_명세_지시서_수용안_반영본

R1(제1권역: 통치와 규범) 통합 아키텍처 명세 지시 문서

목적: 제1권역_통합_마스터.md를 기준(Spine)으로, 업로드된 소스 파일들을 요직(핵심 클러스터) 단위 서브마스터로 재분류·통합하고, 중복/충돌을 정리한 뒤 정본(Real Lore) 문서로 내려쓰기 하기 위한 작업 지시서.

원칙: (1) 기구(기관) 고정 금지: 서브마스터는 기관이 아니라 기능/규범/프로세스 기준으로 편제. (2) 기술 스펙 원장 분리: 기술/무장/코어 스펙은 R4(과학/기술) 원장으로 보내고, R1에는 운용·통제·절차만 남김. (3) 정본에는 선언문만: 논고/비판/레드팀은 서브마스터/부록에 보존, 정본에는 금지.

표기 규칙

  • 주 편입(Primary): 해당 서브마스터의 본문으로 흡수
  • 부록(Annex): 본문이 아니라 부록/근거로 링크 유지
  • 타 권역 이관(Transfer): R1이 아닌 다른 권역(예: R4 기술 원장, R3 사회/계층)에 내려보냄
  • 제외(Exclude): R1 통합 범위에서 제외(다른 레포에 보관은 가능)

2. 서브마스터별 “보강/제외/중복정리” 작업 지시

2-1) R1_Spine(허브) 작업 지시

포함(보강)

  • R1의 목표문: “역량 기반 제한 민주주의 + 제국적 통제의 결합”을 3~6문장으로 확정.
  • 각 서브마스터 링크 + 3~8줄 요약 + 상태(초안/검증중/확정).
  • Issue Queue(쟁점 큐): 충돌/미정/보류 항목을 ID로 관리.

제외

  • 장문 논증, 세부 절차, 표준 외 스펙.

중복정리 규칙

  • 동일 정의가 여러 파일에 있으면 Spine에는 최종 정의 1개만.
  • 근거는 “출처 링크”로만 달기.

2-2) R1A_헌정철학_국가정체성 작업 지시

포함(보강)

  • 용어표(필수): ‘역량’, ‘참정권 자격’, ‘정통성’, ‘삼중 체제(성국/제국/연방)’ 등 핵심 정의.
  • 정치 지형: 정당/정파 블록은 “분류 기준 + 최소 요약”만.
  • ‘다수결 폭정 방지’에 대한 제도적 결론(예: 자격제/견제장치)만 수록.

제외

  • 민주주의 이론 3부작의 장문 본문.
  • 정치철학 논고의 수사/문체/미학적 논증.

    • R1에서 언급한 장비/금기기술이 R4 원장 스펙과 모순 없는가?
    • R1에는 ‘운용/규제’만 있고 ‘스펙/공식’이 남아있지 않은가?

  • 검증 질문
    • 금기기술 통제와 전시 즉결 절차가 특정 역사 사건과 시간·인과 모순을 내지 않는가?

4. 정본(Real Lore) 내려쓰기 프로토콜

4-1) 내려쓰기 규칙

  • 정본에는 확정된 법령/규칙/스펙 선언문만.
  • 반대의견/비판/대안/레드팀은 정본에 절대 포함 금지.
  • 정본 문장은 ‘판결문/시행령’ 톤으로.

4-2) 내려쓰기 순서

  1. Spine의 최종 정의 확정
  2. A→B→C→D 순으로 ‘규범 스펙’ 확정
  3. 교차 검증 완료 표시(체크)
  4. 정본으로 추출(복사)하되, 각 문장에는 원 소스 링크/근거 링크를 메타로만 남김

5. 실행 체크리스트(작업자가 그대로 따라하면 되는 단계)

  1. R1_Spine_... 생성 후 링크 뼈대/Issue Queue 틀 만들기
  2. A/A2/B/C/D1/D2 파일 생성 후 “빈 목차”만 먼저 세팅
  3. 각 입력 소스 파일에서 결론 문장만 발췌해 해당 서브마스터에 편입
  4. 중복 정의는 ‘공통 규칙’ 섹션으로 이동
  5. 기술 스펙/계산식/알고리즘은 즉시 R4 이관 표시
  6. 교차 검증 질문 3세트에 대해 ‘모순 없음/해결 필요’로 표기
  7. 최종 확정된 문장만 모아 R1_Lore_정본_... 생성

6. 메모(추가 확장 옵션)

  • D가 비대해지면 D1/D2 분리는 강제로 전환.
  • B가 비대해지면 ICX와 JSA를 R1B1_ICX / R1B2_JSA로 추가 분리 가능.
