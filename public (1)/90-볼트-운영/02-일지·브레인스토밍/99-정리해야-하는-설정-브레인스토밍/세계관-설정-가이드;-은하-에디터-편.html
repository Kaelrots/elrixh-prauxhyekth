세계관 설정 자료 작성 가이드

Harhaziel 은하 편집기 · M7 및 후속 개발 준비용 · 2026-09-18

처음에는 세계관 개요 1개와 대표 성계 3개만 작성해도 시작할 수 있습니다. 국가·종족·역사 등은 필요한 만큼 추가하세요. 이 문서는 모든 항목을 채워야 하는 제출 양식이 아니라, 어떤 정보를 정하면 편집기의 어떤 기능에 활용할 수 있는지를 정리한 안내서입니다.

설정 내용은 자유로운 글, 표, 목록, 기존 노트 어느 방식으로 작성해도 됩니다. 다만 예정된 M7 최초 가져오기 대상은 UTF-8 Markdown 파일 또는 Obsidian 볼트입니다. Word·스프레드시트 등으로 먼저 작성할 수 있지만 해당 형식의 자동 가져오기는 현재 지원하지 않으며, 실제 연결 전 Markdown으로 옮기거나 별도 변환 방법을 정해야 합니다.

M7은 아직 설계 단계입니다. 최초안은 문서를 기존 성계에 연결해 참조하는 방식이며, 문서에 국가 이름이나 인구를 적는 것만으로 지도 소유권·수치·항로가 자동 변경되지는 않습니다. 아래의 ‘현재 편집기’는 앱 안에서 관리할 수 있는 데이터라는 뜻이고, 해당 정보의 Markdown 자동 반영을 뜻하지 않습니다.

1. 먼저 준비할 최소 자료

자료처음 적을 내용작성 기준
세계관 개요 1개세계관 이름, 지도에 담을 공간 범위, 기준 시점, 주요 전제 3~5개한 페이지 이내로 시작해도 충분
대표 성계 3개이름, 어떤 곳인지, 중요한 특징, 다른 설정과의 관계중심 성계·변경 성계·미정/미탐사 성계처럼 차이가 있으면 연동 확인에 유용
지도 대응 정보각 대표 문서가 연결될 기존 성계의 ID알고 있으면 기록. 모르면 ‘지도 대응 미정’으로 두고 나중에 선택
선택 자료 1개주요 국가 또는 문화권·종족 등 설명대표 성계들이 공통으로 참조할 문서 하나면 충분

집필은 성계 ID 없이 시작할 수 있습니다. 실제 지도 연결 시에는 정확한 ID가 필요합니다. 현재 M7 초안에서는 ID가 없는 문서를 미연결 자료로 남기며, 이름이나 파일명만 보고 성계를 추정해 연결하지 않습니다. 새 성계가 필요하다면 먼저 편집기에서 만들거나 생성한 뒤 그 ID를 사용합니다.

인구나 경제 규모를 아직 정하지 않았다면 억지로 숫자를 만들지 마세요. ‘미정’과 ‘0’을 구분하는 편이 나중에 자료를 정리하기 쉽습니다.

2. 모든 설정에 공통으로 적으면 좋은 정보

정보내용과 예시필요성
이름공식 이름. 예: 아스테르 성계기본
대상 종류성계, 국가, 종족, 문화권, 사건 등기본
설명무엇이며 세계관에서 어떤 역할을 하는지 2~5문장기본
설정 상태확정 / 초안 / 폐기 후보 / 미정권장. 작가의 결정 상태
기준 시점현재 지도 시점, 특정 연도, 사건 전후소속·인구·관계가 시간에 따라 바뀐다면 필요
관련 대상소속 국가, 수도 성계, 인접 지역, 관련 사건 등관계를 표현할 때 필요
별칭다른 언어 이름, 옛 이름, 통칭선택. 이름이 바뀌어도 같은 대상인지 확인하는 데 도움
식별 정보기존 성계 ID, 또는 집필용 관리 코드지도 연결 시 필요. 집필용 코드와 앱 ID는 별개
출처·메모기존 설정집 위치, 수정 이유, 결정이 필요한 내용선택
공개 범위작가용 비밀 / 독자에게 공개 / 특정 세력만 알고 있음선택. 현재 앱의 자동 권한 기능을 의미하지 않음

이름은 바뀔 수 있지만 같은 대상의 ID는 유지하는 것이 좋습니다. 예를 들어 성계 ID "0017"과 "17"은 서로 다른 값입니다. 기존 앱 ID를 새 집필용 코드로 바꾸거나, 숫자로 변환해 앞자리 0을 지우지 마세요.

문서가 여러 대상을 설명한다면 우선 자유롭게 써도 됩니다. 다만 최초 연결 샘플은 성계 하나당 대표 문서 하나가 다루기 쉽습니다. 현재 초안에서는 여러 문서가 같은 성계 ID를 선언하면 충돌로 처리하므로, 보조 문서는 대표 문서에서 링크하는 형태를 사용할 수 있습니다.

3. 데이터 유형별로 준비할 내용

아래 항목은 해당 설정이나 지도 기능을 사용하고 싶을 때 작성합니다. 전부 갖추어야 M7 개발을 시작할 수 있는 것은 아닙니다.

3.1 세계관 전체와 기준 규칙

항목정할 내용활용
공간 범위은하 전체, 특정 성역, 여러 은하 중 하나 등지도와 설정 문서의 대상 범위
기준 시점‘제3차 전쟁 직전’, ‘연합력 420년’처럼 현재 지도의 시점서로 다른 시대의 국경·인구가 섞이는 것을 방지
달력연호, 연도·월·일 표기, 다른 달력과의 대응 여부역사·사건 기록. 시간 변화 기능은 후속 범위
거리와 이동광년·파섹 등의 사용 여부, 초광속 이동의 기본 조건항로 설명과 이동 규칙의 근거
주요 전제국가 간 질서, 알려진 우주 범위, 중요한 기술·자연법칙설정 해석의 공통 기준

현재 편집기의 X/Y는 지도 좌표입니다. 물리 단위 환산은 확정되어 있지 않으므로 좌표 1을 임의로 1광년이나 1kpc라고 간주하지 않습니다. 실제 축척을 쓰고 싶다면 별도로 정할 항목으로 남겨 두세요.

3.2 성계와 장소

항목정할 내용현재 편집기와의 관계
성계 이름·ID·설명표시 이름, 연결할 기존 ID, 역할과 특징이름·ID는 기존 지도에 있음. 설명 문서를 연결할 예정
항성·성계 성격일반 항성, 거성, 중성자별, 블랙홀, 기타 특성별 종류·크기·태그를 관리. 화면 크기와 실제 천체 크기는 별도
행성·위성·거주지이름, 환경, 거주 가능성, 식민지·우주정거장상세 하위 천체 모델은 현재 없으므로 우선 본문에 기록
소유·점령법적 소유 국가, 현재 점령 국가, 중립 여부소유와 점령을 별도로 관리
행정 소속국가와 섹터, 주요 거점 여부성계별 섹터를 관리
탐사·인지어느 국가가 이 성계를 알고 있는지국가별 탐사 상태와 연결 가능
특징·위험유적, 성지, 요새, 자원, 항행 위험 등설명·태그·사용자 속성의 후보

행성 하나의 인구인지 성계 전체 인구인지처럼 정보가 어느 대상에 적용되는지를 함께 적으세요. 행성 설명을 성계 전체의 속성으로 오인하지 않도록 구분하는 것이 중요합니다.

3.3 국가·세력·조직

항목정할 내용현재 편집기와의 관계
정체성공식명, 약칭, 정치 체제, 목표·이념국가 이름을 관리. 체제·이념은 우선 설명
지도 표현대표 색, 문장·깃발의 유무국가 색을 지정할 수 있음. 이미지가 국가 문장으로 자동 연결되지는 않음
수도와 영토수도 성계, 소유 성계, 점령 성계국가·소유권·수도·점령을 관리
구성과 통치주요 종족, 지도자, 통치 구조설명 자료. 별도 인물·통치 구조 모델은 없음
국가가 아닌 조직기업, 종교 단체, 해적, 연구 조직 등의 활동 범위국가와 같은 종류로 볼지 별도 조직으로 둘지 결정 필요

모든 조직에 영토를 줄 필요는 없습니다. 한 성계 안에 여러 기업·단체가 있다고 해서 그 성계의 소유 국가가 여러 개인 것은 아닙니다. 현재 앱은 성계마다 소유 국가 하나와 점령 국가 하나를 기록합니다.

3.4 행정구역·중첩 지역·국경

구분정할 내용구별할 점
섹터·행정구역이름, 소유 국가, 소속 성계현재 성계는 최대 한 섹터에 소속. 소유 국가와 섹터 국가가 일치해야 함
문화권·종교권·경제권이름, 지역의 성격, 포함 성계국경과 별개이며 여러 지역이 중첩될 수 있음
중립·분쟁 지역중립인지 소유권 다툼인지, 당사자와 기준 시점‘소유 국가 없음’과 ‘서로 영유권을 주장함’을 구분
특별 국경자동 계산과 다르게 표시할 범위와 이유필요한 경우 편집기의 수동 국경으로 지정

국경 좌표를 처음부터 손으로 작성할 필요는 없습니다. 우선 어느 성계가 어느 국가에 속하는지 정하면 자동 국경의 근거가 됩니다. 영유권 주장·다단계 행정구역·역사적 국경의 자동 전환은 현재 데이터 기능과 별도로 설계해야 합니다.

3.5 외교와 국가 간 관계

관계적을 내용현재 범위
속국·종주국두 국가, 관계 방향, 성립 시점·조건방향 있는 속국 관계 지원. 자기 종속·순환 관계는 불가
연방이름, 회원 국가, 대표 색, 가입·탈퇴 설명회원국과 색을 관리. 현재 국가는 한 연방에만 가입 가능
동맹·전쟁·휴전·교역 협정당사자, 관계 종류, 시작·종료, 조건우선 문서로 기록. 모든 관계 유형이 구조화되어 있지는 않음
점령·영유권 주장대상 성계·지역, 원소유자, 점령자·주장자점령과 소유는 지원. 여러 영유권 주장은 설명 자료

‘A와 B가 관계가 있다’보다 ‘A는 B의 속국이다’처럼 방향과 의미를 적으면 좋습니다. 지도 문서의 링크는 외교 관계를 자동으로 생성하지 않습니다.

3.6 항로·웜홀·게이트웨이

항목정할 내용활용
양 끝출발·도착 성계의 이름과 ID실제 연결 대상 확인
종류하이퍼레인, 웜홀, 게이트웨이 또는 설정상의 설명현재 지원 종류와 대응
방향양방향인지 단방향인지경로 탐색의 통행 방향
상태·권한사용 가능 여부, 통행 가능한 국가비활성·통행 제한 판단
연결망게이트웨이가 속한 네트워크게이트웨이 연결망 식별
추가 규칙이동 시간, 비용, 장비 조건, 위험·계절성상세 시뮬레이션은 후속 범위로 설명부터 기록

‘두 성계가 서로 관련 있다’는 서술과 ‘직접 이동할 수 있는 항로가 있다’는 설정을 구분하세요. 문서 링크나 ‘웜홀’이라는 태그만으로 항로를 만들지는 않습니다.

3.7 종족·인구·문화·종교

종류정할 내용활용
종족이름, 생물학적·사회적 특성, 모성, 분포설정 문서와 종족별 인구 자료
인구대상 성계, 총인구, 종족별 인구, 단위와 시점현재 정량 정보에 대응 가능
문화이름, 특징, 영향을 받는 성계·지역, 혼합 여부문화권 지역·분류 속성의 근거
종교이름, 교리·성지·신도 분포, 다종교 공존 여부종교권 지역·분류 속성의 근거
비율무엇을 분모로 한 비율인지, 알려지지 않은 몫비율을 사용할 후속 지도 규칙의 근거

종족, 문화, 종교, 국적은 서로 다른 분류입니다. 한 종족을 한 국가나 종교에 자동으로 대응시키지 마세요. 현재 앱의 종족별 인구는 비율이 아닌 수치이며, 합계가 총인구를 넘으면 적용할 수 없습니다. 총인구와 각 종족 수치의 단위를 맞춰야 합니다.

3.8 경제·자원·군사

종류정할 내용활용
경제 성격산업·농업·교역·연구 중심 등 범주경제권 또는 사용자 정의 지도
경제 규모지표의 뜻, 단위, 기준 시점, 값현재 경제 수치에 대응할 때 의미를 확정해야 함
자원자원 종류, 생산·매장·수출 여부, 주요 산지설명·추가 속성 후보. 생산과 매장량을 구분
군사 시설기지·조선소·요새의 위치, 소유자, 역할태그·설명·사용자 지도 후보
군사 전력무엇을 합산한 값인지, 척도·기준, 성계별 값현재 군사 전력 수치의 근거
함대·전투부대 구성, 배치, 이동·전투 규칙현재 전투 시뮬레이션은 없음. 후속 자료

현재 군사·인구·경제 수치는 0 이상의 유한 숫자를 사용합니다. ‘경제 80’만 쓰기보다 ‘경제지수 80점, 기준 연도 420년’처럼 의미를 정하세요. 군사력에서 장비 수·병력 수·추상 점수를 혼합하면 비교할 수 없습니다.

3.9 역사·사건·인물

종류정할 내용현재 활용
사건이름, 시점·기간, 장소, 당사자, 원인과 결과관련 성계의 설명 문서
역사 변화이전 상태와 이후 상태, 변경 이유기준 시점의 소유권·인구 등을 결정하는 근거
인물이름, 역할, 소속, 활동 시기·장소, 관련 사건설정 문서. 별도 인물 관리 기능은 후속 범위
전승·미확인 정보내용, 이야기한 주체, 사실 여부작가의 확정 설정과 등장 세력의 믿음을 구분

현재 지도 데이터는 한 시점의 상태를 다룹니다. 연표를 작성한다고 국경이 시간에 따라 자동 재생되는 것은 아닙니다. 역사 자료는 먼저 본문으로 보관하고, 어느 시점이 현재 지도에 해당하는지 표시하세요.

3.10 이미지·시각 자료

자료준비할 내용현재 활용
지도 이미지·배경파일, 설명, 관련 위치·대상PNG/JPEG/WebP 이미지 레이어. 현재 파일당 12MiB 한도
성운·은하 코어이름, 특징, 대략적인 위치·크기·색편집기에서 시각 항목으로 배치
주석지도에 보일 짧은 문구와 대상주석 레이어
문장·깃발·삽화파일과 대상의 관계, 표시 목적우선 참고 자료. 각 개체와의 자동 연결은 별도 기능

이미지는 최초 세계관 연동의 필수 자료가 아닙니다. M7 최초안의 Markdown 참조 가져오기는 첨부 이미지를 자동 수집하지 않습니다. 시각상의 성운이 자동으로 통행 장애나 군사 효과를 만드는 것도 아닙니다.

4. 나만의 지도 속성을 만들고 싶다면

‘치안’, ‘개척 단계’, ‘기술 수준’, ‘오염도’처럼 기존 항목에 없는 정보도 정의할 수 있습니다. 현재 사용자 정의 지도는 범주 또는 숫자 구간을 지원합니다. 먼저 아래 의미를 정하면 이후 입력·연동 규칙을 만들기 쉽습니다.

정할 항목범주 예시숫자 예시
이름·대상개척 단계 / 성계별치안 지수 / 성계별
값의 뜻미개척, 전초기지, 정착지0~100점, 높을수록 안정
분류·구간각 범주 하나씩낮음: 0 이상 30 미만 / 보통: 30 이상 70 미만 / 높음: 70 이상 101 미만
색상범주별 색구간별 색
미정 처리미지정으로 표시빈 값은 미지정, 0점과 구분
예외 처리등록하지 않은 범주숫자가 아닌 값 또는 구간 밖 값
시점지도 기준 시점조사 기준 연도

숫자 구간은 최솟값 포함·최댓값 제외입니다. 위 예시의 101은 100점을 마지막 구간에 포함하기 위한 경계일 뿐이며, 0~100이라는 설정상 유효 범위를 자동 검증하는 기능은 아닙니다. 구간 밖 값을 어떻게 다룰지도 정하세요. 여러 종교가 공존한다면 대표 종교 하나만 표시할지, 복합 범주나 지역 중첩을 사용할지 별도로 정해야 합니다.

5. 값의 표현과 아직 모르는 정보

데이터 유형작성 예시주의할 점
문자열`아스테르`, `"0017"`ID는 숫자처럼 보여도 문자열로 보존
범주`교역 중심`, `미개척`동의어를 구분하지 않을 계획이면 표기를 통일
숫자`1250000` + 단위 `명`값·단위·측정 대상·시점을 함께 기록
목록관련 종족: 인간, 리안하나인지 여러 값인지 명확히 구분
관계아스테르는 오리온 연합 소유대상과 관계의 의미·방향을 함께 기록

본문역사·특징을 자유롭게 서술본문을 적는 것과 지도 속성 변경은 별개
파일 참조`이미지/오리온-문장.png`대상·용도를 함께 설명

‘미정’은 작가가 아직 결정하지 않은 상태, ‘미상’은 세계관 안에서 알려지지 않은 상태, ‘해당 없음’은 적용 대상이 아닌 상태, ‘0’은 양이 실제로 없는 상태로 구별하면 좋습니다. 현재 앱이 이 상태를 모두 별도 데이터로 저장하는 것은 아닙니다. 집필 자료에 의미를 남겨 두고 실제 입력 규칙을 정할 때 대응시킵니다. 숫자 칸의 빈 값을 임의로 0으로 바꾸지 않습니다.

6. 무엇을 직접 설정하고, 무엇을 편집기에 맡기는가

구분담당 내용
직접 정할 설정이름, 의미, 역사, 소속, 관계, 값의 정의·단위, 기준 시점, 확정 여부
편집기에서 선택·관리할 데이터실제 성계 ID, 지도 좌표, 항로, 국가·섹터 ID, 소유권, 색상, 레이어 배치
편집기가 계산할 결과자동 국경, 최단 경로, 연결 그룹, 고립 성계 진단, 범례와 필터 표시
연동 기능에서 처리할 정보자료원 식별자, 내용 변경 확인용 해시, 가져오기 상태 등. 사용자가 직접 작성할 필요 없음

소유 국가처럼 ‘설정 의미’와 ‘편집기 데이터’ 양쪽에 존재하는 정보도 있습니다. 최초 M7에서는 본문과 지도를 각각 유지하고 참조로 연결합니다. 나중에 자동 반영 기능을 추가할 때 어느 쪽을 원본으로 삼을지 정해야 하며, 두 곳의 값이 다르면 조용히 덮어쓰지 않고 차이를 확인하는 방식으로 설계합니다.

8. 파일 구성과 준비 완료 체크

다음은 선택적인 폴더 예시입니다. 기존 볼트의 폴더명이나 문서 체계를 바꿀 필요는 없습니다.

시작 자료를 준비했다면 다음 정도만 확인하세요.

  • 현재 지도의 기준 시점을 설명할 수 있다.
  • 대표 성계 3개에 이름과 짧은 설명이 있다.
  • 지도에 연결할 ID를 알고 있거나, 대응이 미정임을 표시했다.
  • 미정인 수치를 실제 0으로 적지 않았다.
  • 같은 이름의 다른 대상과 같은 대상의 별칭을 구별했다.
  • 무엇을 먼저 보고 싶은지 골랐다: 문서 설명 / 정치 관계 / 문화·종족 / 경제·군사 / 사용자 속성.

그다음 실제 샘플을 기준으로 성계 ID 대응, 문서 분리 방식, 사용할 속성, 기준 원본과 충돌 처리 규칙을 정하면 됩니다. 세계관 설정 전체를 완성한 뒤 개발을 시작할 필요는 없습니다. 대표 자료로 연동 방식을 먼저 확인하고, 설정과 기능을 함께 확장할 수 있습니다.
