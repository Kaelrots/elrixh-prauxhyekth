99-정리해야 하는 설정: 비-역사 영역 총괄 작업 보고서 (초안 v0.1)

범위: 99-정리해야 하는 설정 브레인스토밍 폴더 내 5개 md 파일 중, 시대 구분·연표·사건사 등 “역사 그 자체”를 제외한 모든 설정·메타 작업 영역에 대한 통합 정리·작업 계획. 목적: 엘리스 프라우셰크트 세계관에서 “시대/연표를 제외한 기반 설정 전반”을 일관된 로드맵 아래에서 정리·집행하기 위한 기준 문서.

1. 전체 개요

1-1. 현재 상황 요약

  1. 아직 정리하지 않은 설정들.md와 아정않설 가이드 (GPT 제안).md는

    • 언어·문자(엘루닉어/엘룬)
    • 카엘 및 주요 캐릭터 설정
    • 신인류/신지구/종족 구조
    • 신화·종교·신화적 존재(4주신, 루벨리니온 제국도교 등)
    • 은하·은하단·성계·우주 지도
    • 국기와 국가(국가/가사/색상 규약)
    • TRPG B루트(잔망의 헬라이오스)
    • 각종 템플릿·메타 도구·자동화 스크립트 아이디어 를 “브레인스토밍 + 작전 지시서” 형태로 묶어 둔 상위 메모.

  2. 구지구, 대전이, 차원간섭.md와 대전이 관련 대화 모음.md는

    • 차원막, 소울 플럭스, 전이 코어 등 구계 차원·대전이 메커니즘
    • 제1차/제2차 대전이의 물리·영적 메커니즘·지형·문명·사상 파급 효과
    • 공식 예측 기관, 플럭스 경보 체계, 데이터·문건 관리 로드맵 등을 이미 비교적 잘 정리한 상태로, 역사 연표와 뒤섞여 있음. → 여기서는 “역사 연표”가 아닌 설정/메커니즘/데이터 구조 부분만을 분리해 비-역사 설정 작업의 일부로 편입한다.

  3. 개선 사항 추천 (GPT).md는

    • 국가/지역/인물/정치/종교/기관 등 기존 템플릿들의 약점·중복·누락을 진단하고,
    • Obsidian·YAML·자동화 스크립트와 맞물리는 메타 템플릿/작업 규범을 제안한 문서. → 이 문서는 “세계관 내용”이라기보다 메타 레벨 도구/프로세스 설정이므로, 별도의 큰 축으로 다룬다.

  4. 시대·연표 관련 작업(라리셴베르크 시대 구분, 제1~3기 역사 개요·하위 사건)은 이미 별도의 작업 보고서/캔버스로 분리되었으므로, 본 보고서에서는 직접적인 역사 작업은 전부 제외하고, 그 주변을 지지하는 기반 설정에 집중한다.

1-2. 이 보고서의 구조

이 문서는 비-역사 설정을 다음 8개 카테고리로 나누고, 각 항목마다

  • (A) 현재 상태
  • (B) 목표 수준(완성형 이미지)
  • (C) 세부 작업 단계
  • (D) 다른 작업(시대/헌법/캐릭터 등)과의 연동 포인트

를 정리한다.

카테고리 목록:

  1. 언어·문자·엘루닉어/엘룬 체계
  2. 카엘 및 캐릭터/혈통 규약 통합
  3. 신인류·종족·능력·신체 색 계층 구조
  4. 신화 시대·신·초월자·종교 설정
  5. 은하·성계·우주 지도 & 구계 차원 모듈
  6. TRPG B루트(잔망의 헬라이오스)와 정사(A루트)의 관계 정리
  7. 국기·국가·상징 체계(국가 정체성 시각 요소)
  8. 템플릿·메타 도구·데이터 관리·자동화

2. 언어·문자·엘루닉어/엘룬 체계

2-1. 현재 상태

  • 엘룬 문자 변환표와 발음 대응표는 1차 버전이 존재하지만,
    • Obsidian 내 일관된 표 형식,
    • IPA/로마자/한국어 병기 규칙,
    • 엘루닉어 문법/형태소·강세 규칙, 을 한 문서 안에서 “완결된 레퍼런스”로 제공하지 못하고 있음.
  • 실제 사용 중인 엘루닉어/엘룬 표기(가문명, 지명, 언어 관련 대화에서 합의한 규칙 등)가 흩어져 있고,
    • 일부는 구버전 로마자 규칙,
    • 일부는 최신 규칙(예: elruhnik/elruhn 고정)으로 표기되어 혼재.
  • 단어집은
    • 국가명/지명/신명/가문명에 쓰인 어근,
    • 노래 가사 번역에서 쓴 단어들,
    • TRPG용 임시 단어집(2~30개) 등으로 조각조각 남아 있는 상태.

2-2. 목표 수준

  1. 마스터 레퍼런스 문서 1개

    • 02-언어/엘루닉어-엘룬 레퍼런스.md (가칭)
    • 다음 내용을 모두 포함하는 “한 번 보면 끝나는” 기준 문서
      • 문자 변환표: 엘룬 문자 → 자모 → IPA → 로마자 → 예시 한국어 발음
      • 발음 규칙·강세: 모음 조화, 음운 동화, 장단·강세 규칙, 단어 경계에서의 변화
      • 형태소·어근 규칙: 자주 쓰이는 접두/접미/어근 의미(예: -h, -rh, -kaim 등)
      • 표기 규칙: 인명/지명/기관명/가문명 등에 대한 엘루닉어·엘룬·한국어 병기 규범

  2. 기본 단어집 + 형태소 사전 분리

    • 단어집: “플레이 도중 자주 쓰는 실제 단어 30+α”를 우선 수록
    • 형태소 사전: 내부적으로 반복되는 형태소(예: rah, el, -kaim 등)를 의미 단위로 정리해 향후 자동 생성/검수에 활용

  3. 도구와의 연계

    • Obsidian Dictionary 플러그인용 CSV 파일 생성
    • 번역 가사/세계관 텍스트에 등장하는 엘루닉어를 자동 하이라이트·팝업 정의로 연결

2-3. 세부 작업 단계

  1. 문자 변환표 통합

    • 기존 변환표/메모를 전부 모아서 하나의 표로 재작성.
    • 열 구조 예:
      • 엘룬 문자 / 엘룬 이름 / 기본 음가(IPA) / 로마자 / 예시(엘루닉어 단어) / 비고
    • 이 표를 기준으로, 이후 모든 엘룬 표기·이미지·폰트 제작 시 통일.

  2. 발음·강세 규칙 문서화

    • 지금까지 대화에서 합의한 발음 경향 + 사용자의 체감 발음 규칙을 정리.
    • 예: 어말 자음군 단순화, 모음 조화, 자주 등장하는 음운 변화 패턴 등.
    • 이 부분은 콜아웃 블록(예: > [!tip] 발음 규칙) 형식으로 작성해 가독성 확보.

  3. 기본 단어집 구축

    • 국명/지명/가문명/신명 등에서 공통으로 등장하는 어근들을 우선 추출.
    • TRPG/노래 가사에서 실제 사용되는 단어를 보충.
    • 표 구조 예:
      • 엘루닉어 / 품사 / 의미 / 예문(한국어) / 등장 문서 링크
    • Obsidian data-table 형식을 사용해 필터·정렬이 가능하도록 작성.

  4. 형태소 사전 분리

    • 단어집에서 반복되는 단위(예: rah = 제도권/황제권? 등)를 찾아 별도의 CSV로 정리.
    • 이 CSV는 추후 자동 변환 스크립트, 이름 생성기, 검수 봇 등에 활용.

  5. 표기 규범 정리

    • “엘루닉어 원형 + 로마자 + 한국어 병기” 기본 패턴을 정의.
    • 가문/지명/국명/기관명 각각에 대해 추천 예시를 제시해, 사용자 본인이 헷갈릴 때 즉시 참고 가능하도록 한다.

2-4. 연동 포인트

  • 역사·시대 작업: 각 시대/국가 이름을 재확인하고, 엘루닉어/엘룬 표기를 일괄 검수.
  • 헌법·기관 설정: 연방 기관 명칭의 엘루닉어 버전을 공식화해, 세계관 내 문서(예: 헌법 부속서)에 병기.
  • 이미지/지도 작업: 지도 상의 문자 표기, 모노리스/플레이 카드 등 비주얼 작업 시 이 레퍼런스를 기준으로 통일.

3. 카엘 및 캐릭터/혈통 규약 통합

3-1. 현재 상태

  • 카엘로츠 관련 설정은
    • 커미션 신청서, 수기 노트, 과거 worldbuilding 문서, 템플릿 샘플 등 여러 곳에 산재.
    • 일부는 최신 설정(혈통 등급, 마나 색상, 신체 색 계층 구조)을 반영하고, 일부는 구버전.
  • 혈통/마나/신체 색 규약은
    • 헌법 제17장(능력자 감독) 및 능력자 관리국 설정,
    • 신인류·신지구 설정,
    • 대전이 이후 “신체 색 = 계급” 문화, 와 맞물려 있지만, 한 곳에 정리된 기준 문서가 없다.

3-2. 목표 수준

  1. 카엘 마스터 시트

    • 카엘로츠 디 하일레이움 (마스터).md (가칭)
    • 내용:
      • 생애 개요 / 시대·정치적 위치 / 혈통·가문 구조
      • 마나 속성·전투 스타일·능력 계열
      • 외형(머리/눈/피부 색, 전투 시 변화 양상)
      • 주요 사건 연표(간략 버전) – 역사는 최소한으로, 캐릭터 이해에 필요한 수준만.

  2. 캐릭터·혈통 규약 문서

    • 캐릭터/혈통-마나-신체색 규약.md (가칭)
    • 내용:
      • 마나 속성 ↔ 대표 색 ↔ 다중 속성 혼합 규칙
      • 혈통 등급(황실/고귀/평민 등)과 신체 색(머리/눈/피부)의 상관관계
      • 전투/마법 사용 시 색 변화 규칙
      • 예시 캐릭터(카엘, 기타 황족, 고위 귀족 등)

  3. 마스터 YAML + 템플릿 연계

    • 캐릭터 템플릿(인물 설정 템플릿)의 상단 YAML 블록에
      • 혈통 등급
      • 기본/전투시 외형 색상
      • 마나 속성 리스트
      • 능력자 관리 등급 을 표준 필드로 넣어, RPG/게임/스토리 문서 간 상호 연동이 가능하게 한다.

3-3. 세부 작업 단계

  1. 자료 수집 및 Diff 비교

    • 카엘 관련 모든 문서를 목록화한 뒤,
      • “가장 최신 커미션 신청서”를 기준본으로 삼고,
      • 과거 설정과 상충·중복 여부를 Diff 표로 만든다.
    • 항목별(혈통, 나이, 외형, 능력, 관계 등)로 최신·우선본을 결정.

  2. 마스터 시트 작성

    • Diff 표에서 확정된 항목만을 모아 새로운 마스터 문서를 작성.
    • 서술 구조는 기존 인물 템플릿 v2 이후 개선안에 맞춘다.

  3. 혈통·마나·신체 색 규약 통합

    • 지금까지의 대화·노트에서 등장한 규칙들을 모아,
      • “원칙 중심”으로 재정리 (예: 백색도 % 기준, 속성 수 제한 등).
    • 예시 표를 충분히 제공해, 새로운 캐릭터를 만들 때 감각적으로 사용할 수 있게 한다.

  4. 템플릿과 동기화

    • 인물 템플릿의 YAML 및 본문 필드에
      • 혈통 등급, 마나 속성, 신체 색 관련 필드를 새로 추가.
    • 기존 캐릭터 문서에도 최소한의 필드를 후속 작업으로 채워 넣는다.

3-4. 연동 포인트

  • 제17장 능력자 감독: 혈통/능력 등급이 법·제도와 어떻게 맞물리는지 연결.
  • 국가·사회 구조: 혈통 계급제가 정치·사회·문화·종교에 끼치는 영향(권리/의무/차별 구조)을 추후 템플릿/국가 설정에 반영.
  • 이미지 작업: 캐릭터 아트/일러스트 프롬프트가 규약과 일관되도록 기준 제공.

4. 신인류·종족·능력·신체 색 계층 구조

4-1. 현재 상태

  • 신인류 정의와 신지구 인류의 진화/융합 과정은 대전이 관련 문서들에 비교적 잘 서술되어 있으나,
    • 종족 분류 체계(순수 신지구 인류 vs 신인류 vs 변이 종족 등),
    • 능력자 등급 체계(마나량·속성 수·혈통 등급과의 관계),
    • 신체 색과 사회 계급의 상세 구조, 는 여기저기 흩어져 언급될 뿐, 단일한 종족·능력 모듈로 정리되어 있지 않다.

4-2. 목표 수준

  1. 종족/계층 정의 모듈

    • 종족-계층-능력자 구조 개요.md (가칭)
    • 내용:
      • 기본 종족군: 신지구 인류 / 신인류 / 혼성체 / 기타 특수 사례
      • 능력자와 비-능력자 구분, 등급 체계(예: E~S 혹은 내부 코드)
      • 신체 색(머리/피부/눈)과 사회 계층/혈통·능력 상관관계

  2. 능력·마법 시스템 개요

    • 마나 속성 리스트(불/바람/벡터/무색 등)와 대표 색, 물리·메타적 의미
    • 다중 속성 운용 시 색 혼합 규칙
    • 능력 발현에 따른 외형 변화 패턴

  3. 사회·정치 구조와의 연결

    • 종족/능력 구조가
      • 황실/귀족/평민 체계,
      • 능력자 감독 제도,
      • 국가·종교 이념, 에 어떻게 반영되는지 큰 그림 수준의 설명을 제공.

4-3. 세부 작업 단계

  1. 기존 설정 스캔 및 분류

    • 대전이 관련 대화 모음, 구지구, 대전이, 차원간섭, 신지구/신인류 개요 문서에서 종족·능력·신체 색 관련 문장을 추출해 리스트화.
    • 중복·충돌·모순 여부를 검토하여, 우선순위 규칙을 정한다.

  2. 종족/계층 정의 정리

    • 최소 단위 분류표 작성:
      • 예: 베이스 종 / 능력 여부 / 혈통 등급 / 신체 색 범위 / 예시 인물.
    • 인게임·TRPG에서 쓰일 수 있도록, “표만 봐도 감이 잡히는” 식으로 구성.

  3. 능력자 등급 체계 설계

    • 마나량·속성 수·제어력·훈련 정도 등을 복합 지표로 하여 등급 체계를 설계.
    • 제17장 능력자 감독의 규정(교육 의무, 소집·통제 권한, 군/기관 배치 등)과 연동해
      • “어느 등급부터 의무 복무/소집 대상인가” 등을 명시.

  4. 시각적 가이드

    • 신체 색/마나 색에 대한 간단한 시각 가이드(예: 색상 팔레트, 레벨별 예시)를 별도 부록으로 작성.
    • 캐릭터 아트, 지도, 카드 디자인에 일관되게 쓰일 수 있도록 한다.

4-4. 연동 포인트

  • 헌법·법제: 제1장 권리장전/제17장 능력자 감독/제3장 황실 등에서, 종족·능력 구조와 합치되게 조문을 점검.
  • 역사 작업: 각 시대에 신인류 비율, 능력자에 대한 사회 인식, 차별·해방·혁명 사건 등을 서술할 때 이 구조를 참조.

4-5. 관련 일지 원문 수집 계획

  • 대상 폴더
    • 07-일지/ 및 그 하위 폴더 전체
  • 포함 규칙
    • 신인류의 정의, 기원, 진화 방식에 대한 서술
    • 인류종/범인류종/아인류종/외인류종 등 종족 구분 아이디어
    • 신체 색(머리/피부/눈)과 계급·혈통·능력의 관계를 언급한 부분
    • 능력자 등급, 수명 구조, 환생·정신체 전이 등 핵심 룰에 대한 메모
  • 제외 규칙
    • 순수한 일상 기록, 감상, 심리 일지 등 설정과 직접 관련 없는 부분

  • 수집 방식

    2. 발췌한 블록을 아래 4-6. 원문 내용(발췌)에 출처 정보와 함께 추가한다.
    3. 각 발췌에는 “반영 상태(✅/🔄/⚠)”와 “요약”을 붙여, 현재 이 보고서 본문(4-1~4-3)에 얼마나 흡수되었는지 표시한다.

5. 신화 시대·신·초월자·종교 설정

5-1. 현재 상태

  • 4주신(젝타르, 사이텝, 이툼, 카엘란)과 성지(루벨리니온, 듀엘로니아, 아카이, 카엘리니아)는 테이블 형태의 초안이 존재.
  • 루벨리니온 제국도교 등의 종교 문서 일부에서
    • 신화적 존재,
    • 신과 초월자,
    • 신화 시대의 조각난 서술, 이 등장하지만, 신화 시대를 독립된 연대기/세계관 레벨로 정리한 문서는 아직 없음.

5-2. 목표 수준

  1. 신화 시대 개요 문서

    • 신화 시대 개요.md (가칭)
    • 내용:
      • 시간적 위치: 역사 제0기 이전/이후의 관계 정의
      • 신·초월자/고대 문명/창세 신화 구조
      • 현재 시대(제1~3기)와의 연결점(전승/유물/종교/마법 기술 기원)

  2. 신 목록·성지·상징 모듈

    • 4주신 + 기타 신/초월자 목록을 표로 정리.
    • 각 신마다
      • 엘룬 표기/엘루닉어/한국어
      • 속성·관장 분야
      • 성지/주요 신전
      • 상징 색/문양/축일 등 을 최소 단위로 기록.

  3. 종교 설정 템플릿과의 연결

    • 기존 종교 설정 템플릿(정통/분파/이단/의례/축제/시각 상징 구조)과 신화 시대 설정을 연결해,
      • “신화 시대 → 종교 교리 → 현대 정치·사회” 흐름이 자연스럽게 이어지도록 한다.

5-3. 세부 작업 단계

  1. 현존 자료 모으기

    • 루벨리니온 제국도교 문서와 관련 하이퍼링크를 따라가며, 신·신화 관련 서술을 전부 클립.
    • 4주신 테이블의 각 항목을 시작점으로, 추가로 필요한 정보(상징, 축제, 금기 등)를 메모.

  2. 신화 시대 타임라인 “느슨한 버전” 작성

    • 아직 세부 연도까지 확정할 필요는 없고,
      • “신/초월자의 시대”
      • “고대 제국/고대 문명 시대”
      • “신화와 역사 사이의 과도기” 정도의 큰 구획만 정의.

  3. 종교 템플릿에 매핑

    • 각 주요 종교(제국도교 등)에 대해
      • 어떤 신화 시대 사건을 교리의 근거로 삼는지,
      • 다른 종교/사상과의 갈등·통합 지점을 간단히 메모.

  4. 현대와의 연결 고리 설정

    • 제2기 이후 헌정·교육·문화에서
      • 신화/종교가 어떻게 해석/축소/세속화되었는지,
    • 대전이 이후 “초월자” 개념이 능력자·마법·과학과 어떻게 접합되었는지, 를 서술해주면, 세계관 톤이 훨씬 풍부해진다.

5-4. 연동 포인트

  • 역사 작업: 신화 시대와 제1기 초기의 경계, 고대문명 흔적, 성지의 위치 등을 역사 연표/지도와 연계.
  • 종교 템플릿: 분파·이단·관용도·축제 구조에 신화적 기원을 집어넣어, 설정의 깊이를 확보.

6. 은하·성계·우주 지도 & 구계 차원 모듈

6-1. 현재 상태

  • 하르아지엘 은하, 루카프탄-사일루트 은하단 등 상위 구조는 명칭·대략적 역할이 정의되어 있으나,
    • 좌표/위치 관계,
    • 성계 간 교통/하이퍼레인 구조,
    • 외우주 진출 시기·루트, 는 아직 “메모 수준”에 머무른다.
  • 구지구, 대전이, 차원간섭, 대전이 관련 대화 모음, 아정않설 가이드는
    • 차원막, 소울 플럭스, 물리/에너지/정신 차원 분류,
    • 전이 코어, 균열, 차원공학·차원 방어술, 등 구계 차원 메커니즘을 이미 상당히 잘 정리해 놓았으나,
    • 이 설정과 “우주 지도/성계·은하・은하단” 구조가 하나의 모듈로 통합되어 있지는 않다.

6-2. 목표 수준

  1. 우주 구조 개요 문서

    • 하르아지엘 은하·루카프탄-사일루트 은하단 개요.md (가칭)
    • 내용:
      • 은하 구조, 은하단 내 위치 관계
      • 주요 성계(류아블론츠 성계 등)의 좌표·역할
      • FTL/차원 항행 기술의 기본 원리

  2. 구계 차원 모듈 문서

    • 구계 차원·차원막·플럭스 개요.md (가칭)
    • 내용:
      • 물리/에너지/정신 차원의 분류
      • 차원막, 소울 플럭스, 전이 코어, 균열 등 핵심 개념 정의
      • 차원공학/차원 방어술의 기술 단계, 위험도, 규제 체계

  3. 성계·은하 지도와 차원 루트의 통합

    • 우주 지도 상에
      • 안정된 차원 항로,
      • 위험 지역(플럭스 과밀, 잔존 균열),
      • 전이 코어의 우주적 분포(있는 경우), 등을 시각적으로 표현할 수 있도록 설정.

6-3. 세부 작업 단계

  1. 현재 설정 인벤토리 작성

    • 류아블론츠 성계, 라리셴베르크 행성, 위성들(6개), 외우주 진출 관련 메모를 한 문서에 정리.
    • 은하/은하단 이름만 적혀 있는 문서들의 위치를 확인하고, “한 줄 설명”이라도 추가.

  2. 우주 지도 1차 버전 스케치

    • 실제 지도를 바로 그리기보다, 텍스트 기반으로
      • “은하단 > 은하 > 성계 > 행성/위성” 계층 구조를 정리.
    • 각 단위에 대해
      • 역할(주요 무대/배경/향후 확장용),
      • 문명 진출 정도,
      • 차원 이상 현상 여부, 를 간단히 메모.

  3. 구계 차원 개념 통합

    • 이미 정리된 차원막·플럭스·전이 코어 설명을, 역사 서술과 분리해 개념 모듈로 재구성.
    • 추가로 필요한 내용(예: 차원 방어 기관, 국제협약, 연구 윤리 규범 등)을 메모 수준으로라도 적어 둔다.

  4. 우주 지도 ↔ 차원 모듈 매핑

    • 각 성계/행성/위성 단위로, 차원 관련 이상·연구 시설·위험도를 표로 정리.
    • 예: “류아블론츠 성계 – 라리셴베르크 – 전이 코어 분포 밀집 / 차원공학 연구 중심지” 등.

6-4. 연동 포인트

  • 역사·시대 작업: 우주시대(A루트)에서 외우주 진출 루트·정책·전쟁/협력 관계를 설계할 때, 이 구조를 기반으로 한다.
  • 국가·외교 템플릿: 은하/성계 규모의 초국가, 행성 간 연합, 항성 간 외교 기구 등 설정에 기본 좌표계를 제공.
  • TRPG B루트: 멸망 루트에서 차원붕괴와 우주 구조가 어떻게 조우하는지, 대체 시나리오 설계의 기반 제공.

7. TRPG B루트(잔망의 헬라이오스)와 정사(A루트) 관계 정리

7-1. 현재 상태

  • B루트(잔망의 헬라이오스)는
    • 제2차 대전이를 막지 못해 차원 침식과 멸망으로 향하는 비극 루트.
    • TRPG용 세계관으로, A루트와 공유하는 설정(대전이, 신인류, 국가·인물 등)이 다수 존재.
  • 현 시점에서는
    • A루트에서 “추후 편입할 수 있는 설정”과,
    • B루트 특유의 멸망·폐허·호러 요소, 가 명확히 구분되지 않은 채, 아이디어 수준으로 묶여 있다.

7-2. 목표 수준

  1. A/B 루트 분기 기준 정리

    • 어느 사건·결정·정책에서 A루트와 B루트가 갈라지는지 “키 분기점”을 정의.
    • B루트용 설정 중
      • A루트에 편입해도 되는 “중립 설정”과,
      • B루트 전용으로 남겨야 하는 “멸망 전용 설정”을 구분.

  2. TRPG 전용 모듈 작성

    • 잔망의 헬라이오스: 플레이어용 개요.md (가칭)
    • 내용:
      • 세계가 이미 얼마만큼 망가져 있는지에 대한 상태 묘사
      • 플레이어 캐릭터의 기본 전제(능력자/신인류/일반인 등)
      • 주요 세력/위험/미션 구조

  3. 정사(A루트)와의 교차 참조

    • B루트 문서 상단에 A루트 기준 타임라인·세계 상태로 되돌릴 수 있는 여지를 남기되,
    • 실제로는 “완전히 분리된 캠페인 모듈”로 관리.

7-3. 세부 작업 단계

  1. B루트 관련 메모 수집

    • 아직 정리하지 않은 설정들 내 B루트/이사 관련 부분, TRPG 샘플, 과거 세션 노트 등을 정리.

  2. 분기점 정의

    • 제2차 대전이 예방/실패를 둘러싼 사건을 중심으로, “여기서부터는 B루트”라는 분기선을 텍스트로 정의.

  3. A루트 편입 설정 추출

    • B루트용 메모 중,
      • 캐릭터 특성, 능력 시스템, 일부 국가 구조 등 “멸망 여부와 무관한 유용한 설정”을 골라내어 A루트 일반 설정으로 편입.

  4. TRPG 모듈 초안 작성

    • 플레이어용 개요/GM용 비밀 설정/세션 아이디어 등으로 나눠 초안 작성.

7-4. 연동 포인트

  • 역사·시대 작업: B루트는 “공식 정사와는 별도의 if 루트”임을 문서 초반에 명시.
  • 능력자·종족·우주 구조: B루트에서도 동일한 규약을 사용하되, 붕괴/왜곡/오염 등 멸망적 변주를 추가하여 맛을 낸다.

8. 국기·국가·상징 체계

8-1. 현재 상태

  • 아직 정리하지 않은 설정들에는
    • 여러 국가·정체성에 해당하는 국기/국가 가사 초안,
    • 일부 번역 가사,
    • 색상·문양 아이디어, 가 브레인스토밍 수준으로 모여 있다.
  • 템플릿 차원에서 “국기·국가·상징”을 체계적으로 수용하는 구조는 아직 부족하다.

8-2. 목표 수준

  1. 국기·국가 마스터 표

    • 국기-국가-상징 개요.md (가칭)
    • 각 국가/정체성 단위로
      • 국기(색상, 문양, 비율)
      • 국가(제목, 작곡/작사자, 기본 정조, 가사 링크)
      • 상징(동물, 식물, 문장, 모토 등) 을 일목요연하게 정리.

  2. 국가 가사/번역 저장소

    • 각 국가별로
      • 원문 가사(엘루닉어 혹은 한국어)
      • 번역(상호 번역 포함)
      • 주석(역사적 배경, 상징 해석 등) 을 별도 문서로 보관.

  3. 국가 설정 템플릿에 상징 필드 추가

    • 국가 템플릿 상단에
      • 국기 색상 코드
      • 상징 동식물
      • 국가/국가 가사 링크 를 필드로 추가해, 다른 문서에서 자동 링크.

8-3. 세부 작업 단계

  1. 기존 가사/국기 메모 정리

    • 현재 존재하는 국기/국가 관련 메모를 전부 찾아 한 문서에 붙인다.
    • 국가명/정체성/진영별로 묶어서 분류.

  2. 국가별 상징 패키지 정의

    • 각 국가에 대해
      • 색상 팔레트(주색/보조색)
      • 국장/문장 혹은 대표 문양
      • 모토(있다면) 를 간단히 설정.

  3. 국가 가사 저장소 구축

    • 하나의 폴더(예: 06-문화/국가-국가)를 만들고,
      • 각 파일에 국가명 + 곡명으로 이름을 붙인다.
    • 파일 내부에는
      • 원문/번역/주석 구획을 명확히 나눈다.

  4. 국가 템플릿 업데이트

    • 국가 설정 템플릿 본문에 “상징·문화” 섹션을 강화.
    • 국가/국기/국가가 역사·정치·군사 설정과 어떻게 연결되는지 예시를 추가.

8-4. 연동 포인트

  • 역사·정치 작업: 국가 상징은 혁명/정권교체/연맹/제국화 등 사건에서 변경될 수 있으므로, 역사 연표와의 동기화 필요.
  • 이미지 작업: 국기/국장/군기/훈장 디자인의 레퍼런스로 사용.

9. 템플릿·메타 도구·데이터 관리·자동화

9-1. 현재 상태

  • 개선 사항 추천 (GPT).md는
    • 국가/지역/인물/정치/종교/기관 템플릿에 대한 진단과 개선안,
    • Obsidian 내 파일 구조/넘버링/인링크 전략,
    • YAML·data-table·스크립트 연계 아이디어, 를 혼합한 “메타 가이드 초안”이다.
  • 이미 일부 템플릿(국가/종교/인물/역사/기관/정책 등)은
    • 피드백 루프를 거쳐 구조가 많이 정제되었으나,
    • 99-정리해야 하는 설정에서 제안된 상위 전략이 전 템플릿에 일관되게 적용되었는지는 아직 재점검되지 않았다.

9-2. 목표 수준

  1. 메타 가이드 정식 문서화

    • 세계관 템플릿·데이터·자동화 메타 가이드.md (가칭)
    • 내용:
      • 폴더/파일 넘버링 원칙
      • 템플릿 공통 원칙(YAML 필수 필드, h2~h6 사용 규칙 등)
      • data-table/Obsidian 플러그인·스크립트와의 연동
      • “정합성 표시” 체계(✅/⚠/❌)와 문서 상태 관리

  2. 템플릿 세트 v2.5 혹은 v3.0 정의

    • 국가/지역/인물/역사/종교/기관/정책/사상/정당 등 주요 템플릿을
      • 각각 최신 피드백 반영본으로 재패키징.
    • 번호/필드/섹션 구성이 상호 호환되도록 통일.

  3. 자동화 스크립트/도구 설계

    • 추후 Python/Obsidian 플러그인/외부 스크립트로 구현할 수 있도록,
      • “해야 할 일”과 “입출력 형식”을 텍스트로 명확히 정의.

9-3. 세부 작업 단계

  1. 개선안 문서 재분해

    • 개선 사항 추천 (GPT).md를
      • 폴더/파일 구조 관련,
      • 템플릿 구조 관련,
      • YAML/data-table/스크립트 관련,
      • 기타 아이디어, 4개 정도의 섹션으로 재분해해 새 메타 문서 초안 작성.

  2. 템플릿 세트 현황 점검

    • 각 템플릿의 최신 확정본을 한 번 훑어보며,
      • 이미 반영된 개선안,
      • 아직 반영되지 않은 제안, 을 체크리스트로 만든다.

  3. 공통 규범 확정

    • 예:
      • 모든 템플릿 상단 YAML에 세계관 루트(A/B), 시대, 관련 국가/인물 필드 공통 적용
      • h2~h6 사용 규칙 (예: # 개요 / 기본 정보 / 세부 설정 / …)
      • 정합성 표식(✅/⚠/❌) 사용 위치와 의미
    • 이 공통 규범은 추후 추가 템플릿(예: 기술/무기/종족 템플릿 등)에도 그대로 확장 가능.

  4. 자동화 후보 정의

    • 예:
      • “역사 사건 문서 ↔ 시대 구분 문서” 상호 링크 자동 생성
      • “인물/국가/기관” 간 관계 그래프 자동 추출
      • “정합성 표식”을 모아 대시보드(어디가 보류/폐기인지 시각화) 구성
    • 이 단계에서는 구현이 아니라, 스펙을 텍스트로 적어 두는 것이 목표.

9-4. 연동 포인트

  • 모든 카테고리: 언어/캐릭터/신인류/신화/우주/국기 등, 앞서 서술한 모든 설정 카테고리가 템플릿·메타 도구 위에서 움직인다.
  • 역사·헌법 프로젝트: 이미 진행 중인 제2연방 헌법, 시대 구분·역사 복각 작업과 동일한 메타 규범을 공유함으로써, 세계관 전체가 하나의 시스템으로 관리된다.

10. 우선순위 및 단계별 로드맵 (비-역사 영역)

10-1. 1단계: 기반 레퍼런스 정리 (우선)

  1. 언어·문자·엘루닉어/엘룬 레퍼런스
  2. 카엘 마스터 시트 및 캐릭터/혈통 규약
  3. 종족·능력·신체 색 계층 구조 개요

→ 이 세 가지는 이후 모든 문서(역사/헌법/캐릭터/국가/이미지 작업)에 계속 영향을 주므로 최우선으로 정리하는 것이 효율적이다.

10-2. 2단계: 메타 구조·템플릿 정비 (중기)

  1. 템플릿·데이터·자동화 메타 가이드 문서화
  2. 템플릿 세트 v2.5/3.0 패키징
  3. 정합성 표식/문서 상태 관리 체계 확정

→ 이 단계까지 완료되면, 이후 새 설정을 추가할 때 항상 같은 규칙과 도구 위에서 작업할 수 있어, 피로도와 혼선을 크게 줄일 수 있다.

10-3. 3단계: 세계관 확장 축 (중~장기)

  1. 신화 시대/신·초월자/종교 설정 개편
  2. 은하/성계/우주 지도 & 구계 차원 모듈 통합
  3. 국기·국가·상징 패키지 구축
  4. TRPG B루트 모듈 정리

→ 이들은 “있으면 세계관의 깊이를 수십 배로 늘려 주는” 영역이라, 1·2단계 기반이 충분히 정리된 뒤에 차근차근 확장하는 것이 좋다.

10-4. 4단계: 자동화 및 시각화 (장기)

  1. Obsidian + 외부 스크립트 기반 자동화 구현
  2. 세계관 상태 대시보드(정합성/보류/폐기/완료) 구성
  3. 지도/그래프/타임라인 시각화 강화

→ 이 단계는 “편의성·가독성·관리 효율”을 극대화하는 작업으로, 본 보고서의 범위를 넘어 실제 구현 단계에서 세부 스펙을 재정리하면 된다.

11. 결론

  • 이 문서는 99-정리해야 하는 설정 브레인스토밍 폴더 내 5개 md 파일의 내용을 기반으로, 시대·연표를 제외한 모든 비-역사 설정 작업의 큰 그림과 세부 액션 아이템을 통합 정리한 초안이다.
  • 이후 실제 작업에서는
    1. 각 카테고리별로 전용 작업 캔버스 또는 md 파일을 열고,
    2. 여기 적힌 순서대로 “자료 수집 → 개요 작성 → 템플릿 연계 → 상호 참조”를 진행하며,
    3. 완료된 항목에는 정합성 표식(✅ 등)을 부여해 상태를 관리하면 된다.
  • 특히, 이미 상당 부분 진행된 시대 구분·역사 복각 작업과 병행할 때,
    • 언어/캐릭터/종족/신화/우주/국기/템플릿 메타가 안정적으로 깔려 있으면,
    • 이후 세부 사건·국가·인물·종교·기관 설정을 쌓아 올리는 속도와 일관성이 크게 향상될 것이다.

이 문서는 v0.1 초안으로, 향후 각 카테고리 작업이 일정 수준 이상 진행되면 v0.2/v1.0 등으로 버전을 올리며 갱신·추가할 것을 권장한다.
