실행 계약

이 문서는 실제 Work 마이그레이션의 실행 기준표다. 구조개편 최종설계안에서 확정된 A~H 결정을 변경하지 않는다. Work는 본 매니페스트에 없는 대규모 구조변경을 임의로 추가하지 않는다. HOLD 항목은 사용자의 추가 결정 또는 명시된 검증이 끝나기 전에는 이동·통합·삭제하지 않는다. 실제 삭제는 원칙적으로 금지하며, 구식·placeholder·사료는 우선 보존 격리한다.

0. v1.1 최종 감사 반영 요약

본 수정본은 구조 설계 A~H를 변경하지 않고 실행 안전성을 보강한다.

주요 수정:

  1. 부모 SUBTREE 이동 후 자식 FROM 경로가 사라지는 실행충돌 제거.
  2. 제1·2·3기 역사와 역사 지도를 연대기/역사지도로 분리.
  3. 신지구.md, 라리셴베르크 마스터, 제1·2·3기 국가 트리, 시각자료 등 누락항목 추가.
  4. 연방 헌법 폴더를 현행 본문과 개정·QA 자료로 세분.
  5. Obsidian 코어 Templates와 Templater 설정 경로 변경을 명시적 실행항목으로 추가.
  6. 카테고리 → 분야 전환 시 폴더명 자동복제 규칙 제거.
  7. 정본상태 허용값을 canon | provisional | draft | archival로 통일.
  8. B루트의 연속성 메타데이터 규칙 추가.
  9. 날짜 역전·형식 오류 QA 추가.
  10. Quartz 90-볼트 운영 공개 제외, 80/98 공개정책 HOLD 추가.
  11. mirror_assets.py/fix_links.py의 basename 평탄화에 대비한 미디어 충돌 사전검사 추가.
  12. 활성 예약작업·자동화 프롬프트의 구 경로 갱신 절차 추가.
  13. 현재 Drive 재검토 결과, 최종설계안은 이미 세계관 루트로 이동되어 있으므로 기존 P4-004G를 제거.
  14. 최종설계안과 본 매니페스트는 마이그레이션 전체 기간 동안 루트에 고정하고, Phase 8에서만 90-볼트 운영/03-작업계획·감사보고/볼트 구조개편/으로 함께 이동.

1. 매니페스트 작성 기준

1.1 식별 기준

  • 명시 가능한 핵심 파일은 개별 파일 단위로 기재한다.
  • 역사·지역·기관처럼 내부 구조가 이미 잘 잡힌 대량 폴더는 SUBTREE 단위로 기재한다.
  • Work 실행 시 각 SUBTREE 하위 파일 목록을 실행 직전에 다시 스냅샷하여 누락 여부를 검증한다.
  • Drive ID가 변하지 않는 move/rename을 우선하며 복사→삭제 방식은 특별한 이유가 없으면 사용하지 않는다.

1.2 정본 판단

  • (보존용·구식 문서) → archival
  • 현행 A루트 + 복원여부:false + 초안/보존 표시 없음 → 기본적으로 현행 정본 후보로 취급
  • 복원여부:true → 기원상태: restored; 정본상태와 별개
  • 복원 경고가 있으면서 현행성 불명확 → HOLD
  • B루트는 80-대체루트·비정사 내부에서 별도 정본 체계를 가진다.

1.3 파일 내용 변경 제한

구조 마이그레이션 단계에서 허용되는 내용 수정은 다음뿐이다.

  1. Frontmatter 스키마 변환
  2. 경로형 위키링크/Markdown 링크 경로 치환
  3. permalink, aliases 추가
  4. MOC·index의 경로 업데이트
  5. 복원정보 조건부 템플릿 반영

설정 내용 자체의 창작·재해석·정합성 봉합은 별도 정본화 작업이다.

이곳은 차원의 장막을 넘어 신지구: 라리셴베르크에 정착한 인류의 방대한 기록 보관소입니다. 엘리시움 신성제국 연방을 중심으로 펼쳐지는 마법과 과학, 역사와 헌정의 이야기를 탐험해 보세요.

🧭 엘리스 프라우셰크트 세계관 탐험 가이드

이 거대한 세계의 10가지 핵심 축을 따라 여행을 시작해 보세요.

  1. 역사의 흐름: 라리셴베르크의 시대 구분 — 선사시대부터 우주시대까지, 문명의 흥망성쇠와 거대한 연대기
    • 구지구의 기억: 제73분기 구지구의 역사 분기점 — 제1차 대전이로 멸망한 제73분기 지구(에아르트)의 엇갈린 역사
  2. 세계의 지도: 지역 목록 — 지구 표면적의 6,003배에 달하는 거대한 행성의 대륙과 전략 요충지
  3. 통치와 법: 엘리시움 연방 헌법 — 신성 제국이자 ‘일극우위 연방’인 국가의 헌정 질서와 통치 구조
    • 구지구의 유산: 제73분기 구지구 국가 설정 — 대전이 이전, 구지구에 존재했던 국가들의 기록
  4. 힘의 원리: 마법 기본설정 — 차원의 섭리를 빌려 세계를 비틀어내는 이능력(마법·신성력·생명력)의 법칙
  5. 행정 체계: 라리셴베르크의 지역 구분 — 거대한 행성을 통치하기 위한 황제직할령과 자치령의 이원화된 행정 구조
  6. 기술 문명: 기술 연구 테크트리 서술 규칙 표준 사전 — 하이퍼레인 개통부터 모노리스 완성, 그리고 기술 게이트(Tech Gate)를 넘어 우주로 향하는 문명의 도약
  7. 신인류의 생태: 신인류 — 차원 간섭으로 진화하여 노화를 극복하고 이능을 각성한 새로운 인류의 생태
    • 영혼의 위계: 초월자 — 영혼의 격(格)을 높여 신의 경지에 다다른 21인의 초월자와 승격의 단계
  8. 차원과 재난: 차원류, 대전이 — 세계를 멸망시켰던 차원 장막의 붕괴(대전이)와 그 전조가 되는 에너지의 흐름(차원류)에 대한 기록
  9. 언어와 문자: 단어집, 현대 엘루닉어 기본설정 — 고대와 현대를 잇는 문자(엘룬)와, 모든 연방 신민을 하나로 묶는 공용어(엘루닉어)의 체계
  10. 시간과 달력: 행성 신지구 라리셴베르크 — 1년이 1,440일(48개월)인 거대 행성의 독자적인 시간 감각과 역법

  • 파일명 단독 위키링크는 동명이인 충돌이 없으면 불필요하게 경로형으로 바꾸지 않는다.
  • 이동 전후 동일명 파일이 둘 이상 생기면 해당 링크를 명시 경로형으로 바꾼다.

8.2 aliases

기존 공개 URL이 확인 가능한 경우 옛 경로를 aliases로 보존한다.

현재 Quartz의 AliasRedirects를 이용한다.

  • Taoism 사용 금지.
  • 제국도교의 道는 제국이 나아가야 할 길·질서·지향을 뜻한다.

  • permalink slug에도 taoism을 사용하지 않는다.

9. 단계별 실행 순서

Phase 0 — 기준선

  1. Git clean 여부 확인 및 사전 tag/commit 생성
  2. 전체 볼트 파일·폴더의 Drive ID + 현재 경로 + MIME + 수정시각 스냅샷 생성
  3. 모든 Markdown/Canvas/JSON/PY/BAT/TS에서 구 폴더명·하드코딩 경로 전수 검색
  4. 현재 broken wikilink·이미지 임베드·Dataview 오류 기준선 기록
  5. Quartz 공개 핵심 URL 목록 저장
  6. 카테고리, 복원여부, draft, (보존용·구식 문서) 전수목록 작성
  7. 미디어 파일의 공백→하이픈 정규화 후 basename 중복 검사
  8. 활성 세계관 자동화·예약작업에서 구 경로를 직접 참조하는 프롬프트 목록 작성
  9. 실제 쓰기 직전 모든 FROM 항목을 Drive ID와 재결합하여 동시 수정 여부 확인

10. Phase 공통 완료 조건

한 Phase는 다음이 모두 참이어야 완료다.

  • 대상 파일/폴더가 TO에 존재
  • 의도하지 않은 중복 파일 없음
  • 옛 경로 참조가 해당 Phase 범위에서 0
  • broken wikilink 수가 기준선보다 증가하지 않음
  • 이미지 임베드 오류 증가 없음
  • Dataview 오류 증가 없음
  • Quartz build 성공
  • 핵심 페이지 렌더 정상
  • HOLD 항목이 자동 처리되지 않음
  • Git diff가 해당 Phase 예상 범위 안에 있음

11. 롤백 원칙

각 Phase 전에 Git commit 또는 tag를 만든다.

예시:

문제가 발견되면 해당 Phase만 롤백한다. 전체 볼트를 한 번에 원복해야 하는 단일 거대 커밋 방식은 사용하지 않는다.

12. Work 실행 지침

Work에 넘길 때 다음을 강제한다.

이 매니페스트와 최종설계안을 실행 기준으로 사용한다.
각 Phase 시작 전 현재 상태를 재확인하고, 종료 후 완료조건을 검증한다.
HOLD 항목은 사용자 승인 없이 처리하지 않는다.
내용의 세계관 정본 판단을 임의로 하지 않는다.
설정 내용 자체를 재작성하지 않고 구조·메타데이터·링크·Quartz 이전만 수행한다.
예상치 못한 충돌은 BLOCKER로 보고하고 다음 독립 항목은 계속할 수 있으나 충돌 항목은 건드리지 않는다.

현재 구조 마이그레이션 자체를 막지 않는 미결정 항목은 다음 하나의 정책 묶음이다.

  • 80-대체루트·비정사를 Quartz에서 공개할지 여부
  • 98-보존·구식 문서를 Quartz에서 공개할지 여부

두 영역은 파일 구조상 예정 위치로 이동할 수 있으나, Quartz 공개/비공개 규칙만 P7-012에서 HOLD한다.
