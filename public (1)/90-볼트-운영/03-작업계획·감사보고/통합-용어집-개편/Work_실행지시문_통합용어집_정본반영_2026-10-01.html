반드시 일관화할 정의

초월자

  • 인간의 육신과 인간의 영혼을 유지함
  • 격·위격·능력·존재 위상이 통상적 인간의 한계를 넘어섬
  • 여전히 인간 존재양식에 속함

신

  • 초월자가 자기 격을 다시 초월
  • 승천하여 인간 육신 의존을 벗어남
  • 영혼 자체가 독립적 존재기반이 됨

초월신

  • 위 경로로 신이 된 존재를 가리키는 제국도교 신학 용어

신앙

  • 신의 존재를 성립시키는 보편적 필수조건이 아님
  • 위격 안정·현현·영향력 등에 영향을 줄 수 있음

금지

다음은 확정하지 않는다.

  • 집단신앙 자체가 별개의 신을 생성한다는 설정
  • 개념·영역 자체가 다른 기원의 신을 생성한다는 설정
  • 비인간 존재에게 인간과 동일한 초월→승천 경로가 적용된다는 설정

이들은 HOLD다.

제국도교 5단계

일반인 → 수도자 → 선지자 → 초월자 → 신

은 제국도교의 수행·교리 모형으로 표현한다. 우주 전체에 강제되는 단일한 객관적 순서로 쓰지 않는다.

  • 라리셴베르크의 시대 구분.md
  • 관련 역사 index 및 연표

반영 규칙

  • 무표기 제1기 = 제1기 역사시대 전체
  • 광의의 제1기라고 쓸 때만 제1차 대전이·비역사 시기까지 포함
  • 비역사 시기는 상위 전환구간
  • 비역사 시대는 제1차 대전이 이후~제2기 개막의 구체시대
  • 제2차 대전이 이전은 공통역사
  • A루트 = 정사 《엘리스 프라우셰크트》
  • B루트 = 이사·대체루트 《잔망의 헬라이오스》

B루트 멸망 설정을 A루트에 혼입하지 않는다.

  • 엘룬 = 문자

  • 음운체계
  • 문자 목록
  • 전사법

5. 통합 용어집에 넣지 않을 것

다음은 통합 용어집에 올리지 않는다.

  • TMC, gate_id, tree_map, rel_type 등 볼트 메타데이터
  • 개별 함선·무장·센서·모듈
  • 독립 원전이 없는 대화 수집 후보
  • 외부 게임 참고를 그대로 세계관 용어화한 항목
  • HOLD 상태의 미확정 수치·장비·계측법

6. 수정 방식

6.1 최소수정 원칙

  • 설정이 이미 07과 일치하면 문장을 억지로 다시 쓰지 않는다.
  • 정의 충돌·다의성·구식 설명이 있는 부분만 수정한다.
  • 원문의 문체·표 구조·Obsidian/Quartz 링크 형식을 유지한다.
  • HTML을 새로 늘리지 않는다.
  • 가능하면 기존 heading/anchor를 유지한다.

6.2 링크·별칭

정식 표제와 별칭을 다음처럼 정리한다.

마나 회로, 각성, 초월 각성, 비역사 시기, 비역사 시대처럼 서로 다른 개념은 aliases로 합치지 않는다.

7. QA 필수항목

모든 수정 후 다음을 검사한다.

  1. 깨진 위키링크 없음
  2. 잘못된 anchor 없음
  3. 중복 표제어 없음
  4. aliases 충돌 없음
  5. 공통 용어와 전문사전 정의가 서로 모순되지 않음
  6. D/P/국소충돌 결정이 누락되지 않음
  7. HOLD가 정본으로 승격되지 않음
  8. B루트가 A루트에 혼입되지 않음
  9. 구식 헌정 설명이 현행 헌법보다 우선하지 않음
  10. 복원 마법 문서의 미확정 수치가 정본화되지 않음
  11. 차원인정 오탈자 잔존 여부 검사
  12. 전이계가 제4차원으로 남은 곳 검사
  13. 혼류=차원류 전체로 오독되는 문장 검사
  14. 7성급=초월자 식 등치 검사
  15. 신앙 필수=신 존재 절대명제 잔존 검사
  16. 엘룬=언어 또는 엘루닉어=문자 역전 표기 검사
  17. 기존 28개 통합용어 링크 호환성 검사

8. 완료 보고 형식

Work는 완료 후 반드시 다음을 보고한다.

8.1 변경 파일 목록

각 파일마다:

  • 파일명
  • Drive ID
  • 이전 경로 / 현재 경로
  • 정본상태
  • 수정 유형
  • 핵심 변경사항
  • 근거 결정 ID

8.2 신규 파일

신설한 전문사전·index가 있으면:

  • 생성 이유
  • 기존 파일로 대체할 수 없었던 이유
  • 역할
  • 연결된 원문 목록

8.3 HOLD

반영하지 않은 항목을 전부 목록화하고, 왜 보류했는지 기록한다.

8.4 검증

  • 링크 검사
  • 용어 충돌 검사
  • 정본상태 검사
  • 별칭 검사
  • 핵심 문자열 검색 결과
  • 수정 전후 diff 요약

8.5 최종 판정

다음 중 하나로 끝낸다.

  • PASS — 전체 반영 및 QA 완료
  • PASS WITH HOLD — 확정 범위 반영 완료, HOLD는 미반영
  • BLOCKED — 정본 식별 또는 충돌 때문에 사용자 판단 필요

사용자가 이미 07에서 확정한 문제를 다시 질문하지 않는다. 새로운 진짜 충돌이 발견된 경우에만 BLOCKED 항목으로 보고한다.

9. 절대 금지

  • 07 결정을 임의 재설계
  • HOLD를 추론으로 채움
  • 과거 복원문서 전체를 최신 정본으로 승격
  • 보존용·구식 문서 수정
  • B루트를 A루트 정사로 병합
  • 통합 용어집을 세부설정·수치 백과사전으로 비대화
  • 동일 역할 전문사전을 이유 없이 중복 생성
  • 실제 정본을 찾지 않고 파일명만 보고 무작정 수정
