# 세계관 설정 자료 작성 가이드

Harhaziel 은하 편집기 · M7 및 후속 개발 준비용 · 2026-09-18

<font style="font-weight:bold">처음에는 세계관 개요 1개와 대표 성계 3개만 작성해도 시작할 수 있습니다.</font> 국가·종족·역사 등은 필요한 만큼 추가하세요. 이 문서는 모든 항목을 채워야 하는 제출 양식이 아니라, 어떤 정보를 정하면 편집기의 어떤 기능에 활용할 수 있는지를 정리한 안내서입니다.

설정 내용은 자유로운 글, 표, 목록, 기존 노트 어느 방식으로 작성해도 됩니다. 다만 예정된 M7 최초 가져오기 대상은 <font style="font-weight:bold">UTF-8 Markdown 파일 또는 Obsidian 볼트</font>입니다. Word·스프레드시트 등으로 먼저 작성할 수 있지만 해당 형식의 자동 가져오기는 현재 지원하지 않으며, 실제 연결 전 Markdown으로 옮기거나 별도 변환 방법을 정해야 합니다.

M7은 아직 설계 단계입니다. 최초안은 <font style="font-weight:bold">문서를 기존 성계에 연결해 참조하는 방식</font>이며, 문서에 국가 이름이나 인구를 적는 것만으로 지도 소유권·수치·항로가 자동 변경되지는 않습니다. 아래의 ‘현재 편집기’는 앱 안에서 관리할 수 있는 데이터라는 뜻이고, 해당 정보의 Markdown 자동 반영을 뜻하지 않습니다.

<font style="font-weight:bold">집필은 성계 ID 없이 시작할 수 있습니다. 실제 지도 연결 시에는 정확한 ID가 필요합니다.</font> 현재 M7 초안에서는 ID가 없는 문서를 미연결 자료로 남기며, 이름이나 파일명만 보고 성계를 추정해 연결하지 않습니다. 새 성계가 필요하다면 먼저 편집기에서 만들거나 생성한 뒤 그 ID를 사용합니다.

인구나 경제 규모를 아직 정하지 않았다면 억지로 숫자를 만들지 마세요. ‘미정’과 ‘0’을 구분하는 편이 나중에 자료를 정리하기 쉽습니다.

이름은 바뀔 수 있지만 같은 대상의 ID는 유지하는 것이 좋습니다. 예를 들어 성계 ID `"0017"`과 `"17"`은 서로 다른 값입니다. 기존 앱 ID를 새 집필용 코드로 바꾸거나, 숫자로 변환해 앞자리 0을 지우지 마세요.

문서가 여러 대상을 설명한다면 우선 자유롭게 써도 됩니다. 다만 최초 연결 샘플은 <font style="font-weight:bold">성계 하나당 대표 문서 하나</font>가 다루기 쉽습니다. 현재 초안에서는 여러 문서가 같은 성계 ID를 선언하면 충돌로 처리하므로, 보조 문서는 대표 문서에서 링크하는 형태를 사용할 수 있습니다.

소유 국가처럼 ‘설정 의미’와 ‘편집기 데이터’ 양쪽에 존재하는 정보도 있습니다. 최초 M7에서는 본문과 지도를 각각 유지하고 참조로 연결합니다. 나중에 자동 반영 기능을 추가할 때 <font style="font-weight:bold">어느 쪽을 원본으로 삼을지</font> 정해야 하며, 두 곳의 값이 다르면 조용히 덮어쓰지 않고 차이를 확인하는 방식으로 설계합니다.

## 7. 바로 복사해서 쓸 수 있는 작성 틀

아래 한글 항목은 집필용 양식이며 고정된 가져오기 필드명이 아닙니다. 항목을 없애거나 늘려도 됩니다. 미정 부분은 그대로 남겨도 됩니다.

### 세계관 개요

```markdown
# [세계관 이름]
- 공간 범위:
- 현재 지도 기준 시점:
- 사용하는 달력:
- 거리·이동의 기본 규칙:
- 주요 전제:
- 주요 국가·세력:
- 먼저 지도에서 확인하고 싶은 정보:
- 아직 결정하지 않은 부분:
```

### 성계 대표 문서

```markdown
# [성계 이름]
- 종류: 성계
- 설정 상태: 초안
- 지도 성계 ID: 지도 대응 미정
- 기준 시점:
- 한 줄 설명:
- 소유 국가:
- 점령 상태: 해당 없음 / 미정 / 국가명
- 행정구역:
- 주요 천체·거주지:
- 인구·단위·시점: 미정
- 주요 종족·문화·종교:
- 경제·군사 특징:
- 탐사·인지한 국가:
- 직접 이동 가능한 성계:
- 관련 문서:

## 상세 설정

## 역사와 사건

## 결정할 내용
```

### 국가 또는 세력 문서

```markdown
# [국가·세력 이름]
- 종류: 국가 / 비국가 조직
- 설정 상태: 초안
- 기준 시점:
- 공식명·별칭:
- 정치 체제·목표:
- 수도 또는 주요 거점:
- 소유 성계와 주요 활동 지역:
- 주요 종족·문화:
- 다른 국가와의 관계:
- 대표 색·문장: 미정
- 관련 문서:

## 상세 설정

## 성립과 변화
```

### 임의의 종족·문화권·사건 문서

```markdown
# [이름]
- 종류:
- 설정 상태:
- 적용 시점 또는 기간:
- 설명:
- 관련 성계·국가·인물:
- 특징 또는 발생 배경:
- 다른 설정에 미치는 영향:
- 결정할 내용:
```

### 향후 Markdown 연결용 메타데이터 예시

기존 지도에서 ID를 확인한 성계 대표 문서는 다음과 같은 머리말로 대응시킬 수 있습니다. <font style="font-weight:bold">키 이름과 해석은 아직 M7 설계 초안이며, 현재 앱의 가져오기 기능이 아닙니다.</font> 아래 `0017`과 이름도 예시이므로 실제 문서에는 본인의 성계 ID와 이름을 써야 합니다.

```markdown
---
harhaziel_system_id: "0017"
title: "아스테르 성계"
---
# 아스테르 성계
오리온 연합의 교역 거점이다.
관련 설정: [[국가/오리온 연합]]
```

`harhaziel_system_id`는 성계 대표 문서에만 사용합니다. 국가 문서에 수도의 성계 ID를 넣으면 국가가 아니라 수도 성계의 대표 문서로 오인될 수 있으므로, 수도는 본문이나 링크로 적으세요. 국가·종족 자체의 구조화된 연결 키는 아직 정하지 않았습니다. ID를 모르는 문서는 이 머리말을 생략해도 됩니다.

## 8. 파일 구성과 준비 완료 체크

다음은 선택적인 폴더 예시입니다. 기존 볼트의 폴더명이나 문서 체계를 바꿀 필요는 없습니다.

```text
세계관/
  세계관 개요.md
  성계/
    아스테르.md
    변경 거점.md
    미탐사 성계.md
  국가/
    오리온 연합.md
```

시작 자료를 준비했다면 다음 정도만 확인하세요.

- [ ] 현재 지도의 기준 시점을 설명할 수 있다.
- [ ] 대표 성계 3개에 이름과 짧은 설명이 있다.
- [ ] 지도에 연결할 ID를 알고 있거나, 대응이 미정임을 표시했다.
- [ ] 미정인 수치를 실제 0으로 적지 않았다.
- [ ] 같은 이름의 다른 대상과 같은 대상의 별칭을 구별했다.
- [ ] 무엇을 먼저 보고 싶은지 골랐다: 문서 설명 / 정치 관계 / 문화·종족 / 경제·군사 / 사용자 속성.

그다음 실제 샘플을 기준으로 성계 ID 대응, 문서 분리 방식, 사용할 속성, 기준 원본과 충돌 처리 규칙을 정하면 됩니다. <font style="font-weight:bold">세계관 설정 전체를 완성한 뒤 개발을 시작할 필요는 없습니다.</font> 대표 자료로 연동 방식을 먼저 확인하고, 설정과 기능을 함께 확장할 수 있습니다.
