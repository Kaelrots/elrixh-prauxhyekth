# WORK 시작 지시문 — 세계관 데이터 V2 분야별 독립 파일 전환

## 먼저 읽을 파일

같은 폴더의 `01_세계관_데이터_V2_분리고도화_WORK_작업계획서.md`를 실행 기준으로 읽는다. `02_기존87개시트_이관대응표.csv`는 실제 첨부본의 36+51개 탭을 모두 포함하며, `03_검증_체크리스트.csv`에는 84개 미실행 시험이 있다. `05_첨부본_구조점검.json`은 온라인 실행 결과가 아닌 첨부 XLSX 구조 관측이다.

## 수행 지시

기존 두 원본은 수정·이동·권한 변경하지 말고, 별도 V2 운영 파일 16개로 분야별 분리·고도화를 수행한다. 탭만 재배치하는 작업으로 대체하지 않는다.

원본은 다음 두 파일 ID로 식별한다.

```text
REG-V1: 1EACdRIiAPGk4LAbttpXZiJd_cuqIh-cVi4jQsbfmqDw
NAT-V1: 1mTRKFfCFtiTmuAR6QwrslcBI6Q-wutYzVP_weDAW9uI
```

PH0에서 실제 온라인 원본·권한·탭·범위를 다시 읽고 실행시점 백업 및 첨부본 대비 차이를 기록한다. 기존에 이 프로젝트의 실행상태가 존재하면 실제 파일 ID와 원본 변경 여부를 확인하고 재개하며, 같은 파일/자료를 중복 생성하지 않는다.

PH1~PH7을 계획서의 의존 순서와 단계별 완료 기준에 따라 수행한다. 실제 수행한 항목만 완료/통과로 기록한다. 16개 기본 운영 파일, 모든 실제 필드의 대응, 원본 단일화, 순환 연결 제거, 기존 조회·선거·임기·황실·경제 기능 계승을 우선한다.

설정이 미정이거나 서로 충돌하면 원문과 판본을 보존하고 결정대기표에 올린다. 행성 수치·종족 분류·제도·인구·GDP 등을 창작해서 채우지 않는다. 기존 ID는 보존하고, 지역 영토관계는 R50, 인물은 N30, 모든 공직 임기(황제 포함)는 N20에서 한 번만 입력하도록 한다.

N20은 N30의 인물 표를 읽되, N30이 N20 재위 표를 다시 import하는 순환은 만들지 않는다. 반대 방향의 기간·존재 검증과 복합 조회는 H90에서 수행한다. V1 주소와 XLSX 호환 수식 래퍼를 V2 운영식으로 남기지 않는다.

오류·권한 문제·자료 없음·초안·부분합·미실행을 서로 구별한다. `IFERROR(...,0)` 등으로 연결 실패를 정상 수치처럼 숨기지 않는다. 표 범위를 늘릴 때 입력·계산·검증·제공·소비 범위를 함께 갱신하고 시험한다.

## 저장·중단·완료

별도 목적지가 없으면 계획서의 `내 드라이브/ChatGPT/세계관 데이터 V2` 구조를 사용한다. 실제 생성 파일 ID·폴더 ID·이관 배치·검증 결과를 단계마다 저장한다. 작업이 나뉘면 실행상태와 다음 안전한 단계가 남도록 하고, 완료를 예고만 하지 않는다.

최종 보고에는 실제 16개 운영 파일 링크, 이관·보존·변환 내역, 시험 통과/실패/미실행 수, 미해결 정본 쟁점, V1 무변경 확인, 백업·복구 위치와 H90 진입 링크를 포함한다.

온라인 권한·재계산·시험이 미완료면 전체 완료라고 보고하지 않는다. 기존 외부 링크나 V1 사용을 강제로 끊지 않으며, 별도 운영 전환 승인이 없으면 `V2 기술 구축 완료 · 운영 전환 대기`로 구분한다.
