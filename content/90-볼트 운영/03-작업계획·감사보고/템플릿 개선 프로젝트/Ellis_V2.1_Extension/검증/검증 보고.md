## 확인 환경과 한계

시작형의 단일 Templater 실행 블록을 JavaScript로 실행했다. Vault·편집기·날짜·include API는 모의 환경이며 YAML·Markdown은 실제 파서로 처리했다. <font style="font-weight:bold">실제 Templater 플러그인과 WASM 파서는 실행하지 않았다.</font>

Obsidian·Prism의 실제 화면, Quartz 전체 빌드·공개 제외, 기존 쿼리·추출기의 신규 세부유형 처리는 미검증이다. 따라서 이 결과를 실사용 화면 호환 확정이나 기존 V2 승격 완료로 해석하지 않는다. [재검증 안내](<재검증 안내.md>)에 후속 확인 절차를 제공한다.

## 원본 보존

Drive 자료는 읽기·다운로드만 수행했고 수정하지 않았다. 배포용 `vault` 트리에는 기존 SSOT나 공통 생성기를 넣지 않았으며 신규 조합기가 기존 운영 원본을 호출한다. 참고 사본은 설치 트리 밖에 둔다. 기존 종족 V2의 이름·분류·내용도 수정하지 않았다.

SSOT 참고 사본은 조회된 텍스트를 UTF-8·LF로 보관한 내용 스냅샷이다. 공통 생성기 참고 사본은 다운로드한 원본 바이트이며 로컬 사본 해시가 원본 다운로드 해시와 같다. 원격 파일의 이후 변경까지 동결하거나 보장하지 않는다.

## 배포 무결성

전체 파일의 SHA-256은 `checksums.sha256`, 파일별 역할과 조합은 `manifest.json`을 기준으로 한다. manifest의 파일 목록은 manifest와 체크섬 파일 자신을 제외한다. 체크섬 파일은 자신만 제외한다. ZIP 완성 후 CRC, 파일 수·이름, 전체 파일 해시, 매니페스트를 다시 검사한다.
