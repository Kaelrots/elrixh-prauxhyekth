# 재검증 안내

`verify.cjs`는 Node.js 환경에서 패키지의 원문·구성·조합기를 읽어 검사한다. 사용자 볼트나 원격 파일에는 접근하지 않는다. 검증용 Vault·편집기·Templater include·날짜 API를 메모리에서 제공하고 실제 V2 공통 생성기와 실제 YAML·Markdown 파서를 호출한다. 실제 Templater WASM 파서나 Obsidian 화면을 실행하는 검사는 아니다.

패키지를 별도 작업 폴더에 푼 뒤 이 `검증` 폴더에서 실행한다.

```text
npm install --ignore-scripts --no-audit --no-fund
npm test
```

의존성 다운로드에는 네트워크가 필요하다. 템플릿 실사용에는 이 검증용 Node.js 패키지가 필요하지 않다. 재검증 시 `자동검증 결과.json`과 본문 미리보기를 다시 작성하므로 배포 ZIP을 보존하고 복사본에서 실행한다. 다시 작성한 파일은 최초 배포본의 체크섬과 달라질 수 있다.

검증 결과의 시각은 현실 실행 시각 대신 고정 입력 `2026-10-03T12:34:56`을 사용한다. 이는 문자열 자료형·날짜 형식 검사를 위한 값이며 문서의 작중 시점 또는 실제 작성 시각으로 사용할 예시가 아니다.

## 화면 확인 절차

1. 복사 볼트에 공통 의존성과 확장 파일을 설치하고 실제 Templater로 대표 시작형을 삽입한다.
2. Properties에서 제목·분류·리스트·불리언·상태·버전·날짜를 확인한다.
3. Prism 및 기본 테마에서 Core·행성·문자·국적·종교 공동체 상세형의 제목·표·Callout·링크를 확인한다.
4. 좁은 화면에서 4열 표를 확인하고 장문이 있으면 표 밖 문단으로 옮긴다.
5. Quartz 복사 환경에서 템플릿·참조·검증·미리보기·작업 메모가 의도대로 제외되는지 실제 빌드로 확인한다.
6. 기존 V2 문서 생성·조회가 유지되는지 확인한 뒤 실사용에 추가한다.

여기 적힌 화면 확인은 수행 지침이며 수행 완료 기록이 아니다.
