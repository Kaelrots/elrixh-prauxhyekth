# 확인한 V2 원문

이 폴더는 설치 대상이 아니다. 기존 V2의 공통 Frontmatter와 생성기 규격을 재현하고 검증하기 위한 참고 사본이다. 기존 볼트에 두 번째 공통 원본으로 추가하거나 기존 파일을 덮어쓰지 않는다.

- `00-yaml 속성탭.md`: Drive에서 읽은 Markdown 텍스트. UTF-8·LF로 저장했고 원문 내용을 변경하지 않았다. 전송 전 바이트와의 동일성까지 주장하지 않는다.
- `render_frontmatter.js`: Drive가 제공한 인증된 파일 참조에서 받은 원본 바이트. 실행 로직을 수정하지 않았다.
- `출처.json`: SSOT·원칙·시작형 목록·통합 보고의 URL과 수정 시각.

공통 생성기 원문: https://drive.google.com/file/d/1Gu-C6xP-Yrt_2jDeVqBu7jPfDQFD4Msw/view

기존 V2의 실제 화면 QA·승격 상태를 이번 패키지에서 변경하지 않는다. V2.1의 참고 사본 수정으로 원격 원문이 변경되지는 않는다.
