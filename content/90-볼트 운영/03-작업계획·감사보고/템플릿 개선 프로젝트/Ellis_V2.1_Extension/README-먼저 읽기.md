# 《엘리스 프라우셰크트》 템플릿 V2.1 신규 확장 패키지

<font style="font-weight:bold">패키지 2.1.0 · 2026-10-03 · 12계열 / 문서 시작형 35개</font>

기존 V2를 그대로 둔 채 추가할 수 있는 확장 패키지다. 공통 Frontmatter 스키마는 <font style="font-weight:bold">2.0.0</font>을 계승하며, 패키지·템플릿 버전 <font style="font-weight:bold">2.1.0</font>과 구별한다. 새 문서는 Core부터 작성하고 필요한 상세 장만 추가한다.

## 가장 빠른 시작

1. [설치·사용 안내](<안내/설치·사용 안내.md>)의 기존 V2 설치 여부와 공통 파일을 확인한다.
2. ZIP의 `vault` <font style="font-weight:bold">안쪽 두 추가 경로만</font> 볼트에 합친다. 기존 파일 교체 요청이 나오면 멈추고 중복 설치 여부를 확인한다.
3. 볼트의 템플릿 폴더 밖에서 제목을 정한 빈 새 노트를 만든다.
4. Templater로 `V2.1 신규 확장/시작형`의 해당 <font style="font-weight:bold">Core</font>를 삽입한다.
5. 한 줄 요약과 핵심 프로필부터 채운다. 이후 필요한 구성요소 본문만 복사한다.

Templater 없이 내용을 살펴볼 때는 아래 계열명을 눌러 <font style="font-weight:bold">Core 본문</font>을 읽으면 된다. 원본 시작형 파일은 생성기 호출용이므로 Markdown 본문과 분리되어 있다.

## 계승과 범위

기존 `01~11`, 번호 없는 종족 V2, `80`·`90` 계열의 파일명·내용·호출 경로를 바꾸지 않는다. 확장 식별자는 별도 이름공간 <font style="font-weight:bold">X21-01~X21-12</font>를 사용한다. 순번을 기존 템플릿 번호에 끼워 넣지 않는다.

X21-07 종족은 기존 종족 V2를 유지한 채 새 문서에서 선택할 수 있는 확장이다. 같은 종족의 기준 문서를 중복 생성하지 않는다. 법률·헌법·황제령 등 법령계는 포함하지 않는다. X21-04의 법칙은 자연·초자연 작동 법칙이며, 국적·시민권 계열은 사람들의 소속과 공동체를 다룬다.

<font style="font-weight:bold">실사용 화면 확인은 별도다.</font> 이 패키지의 자동 검사 범위와 Obsidian·Prism·Quartz에서 아직 확인하지 않은 항목은 [검증 보고](<검증/검증 보고.md>)에 명시한다. 패키지 작성 완료가 기존 V2의 승격·이관·게시를 뜻하지 않는다.
