# 설치·사용 안내

## 기존 V2가 있는 볼트에 추가

먼저 원본 볼트의 복사본에서 확인한다. 이번 ZIP은 기존 V2 전체 배포본을 대체하지 않는다.

필요한 기존 파일은 다음 두 개다.

- `90-볼트 운영/00-템플릿/00-yaml 속성탭.md`
- Templater의 기존 User Script Folder에 있는 `render_frontmatter.js`

이 파일들은 이번 작업에서 수정하지 않았다. 확인한 원문은 `참조-설치대상아님`에 보관했다. 설치 시 새 사본을 덮어쓰는 대신 현재 V2와 규격을 비교한다. 참고 원문이 볼트에 두 벌의 운영 SSOT로 등록되지 않도록 한다.

1. `vault/90-볼트 운영/00-템플릿/V2.1 신규 확장` 폴더 전체를 같은 상대 경로에 추가한다.
2. `vault/90-볼트 운영/00-템플릿/유저 스크립트/render_extension_v21.js`만 기존 User Script Folder에 추가한다. 기존 스크립트는 유지한다. 스크립트 폴더가 다른 경우 새 JS만 그곳에 복사한다.
3. Templater의 Template Folder가 `90-볼트 운영/00-템플릿` 또는 그 상위 경로를 포함하는지 확인한다. User Script Folder는 기존 값을 사용한다.
4. Templater가 새 스크립트를 인식하도록 플러그인을 다시 불러온다. 전역 Node 모듈이나 네트워크 연결은 템플릿 사용에 필요하지 않다.
5. 템플릿 폴더 밖의 빈 새 `.md` 노트에 Core 시작형을 삽입한다. 내용이 있는 노트나 템플릿 자신에 삽입하면 공통 생성기가 거부한다.
6. 제목·분류·상태·배열·날짜가 생성됐는지 확인한다. 생성 후 문서 제목과 필요한 메타데이터를 편집한다.

파일·폴더 경로를 임의로 바꾸면 구성요소 조회가 실패한다. 본문은 조합 후 일반 Markdown이므로 읽기에는 Templater가 필요하지 않다. 구성요소 수정이 이미 생성된 문서를 자동으로 바꾸지는 않는다.

## V2가 없는 시험 볼트

빈 시험 볼트에 한해서 `참조-설치대상아님/00-yaml 속성탭.md`를 위 공통 경로에, `render_frontmatter.js`를 User Script Folder에 <font style="font-weight:bold">한 벌씩</font> 배치한 뒤 `vault` 추가분을 설치할 수 있다. 이는 실사용 V2 파일의 교체가 아니다. 시험 볼트와 실사용 볼트의 공통 원본을 함께 운영하는 것으로 해석하지 않는다.

## Core → 필요한 상세 장

Core·상세형은 같은 대상을 두 문서로 나누라는 뜻이 아니다.

- 아직 문서가 없으면 <font style="font-weight:bold">Core</font> 또는 <font style="font-weight:bold">상세형</font> 중 하나를 골라 한 번 생성한다.
- Core를 이미 작성했다면 `구성요소/X21-번호-계열명`에서 필요한 `M…` 본문만 복사해 <font style="font-weight:bold">관련 문서·근거 앞</font>에 붙인다.
- 프론트매터·Core·공통 문서관리 장을 다시 붙이지 않는다. 상세형 전체를 기존 노트에 삽입하지 않는다.
- 천체·우주지리 상세형은 공통 관측·물리량까지만 포함한다. 은하·성계·항성·행성 중 맞는 모듈을 선택한다.
- 개념 상세형은 개념 정의, 능력 상세형은 체계 운용, 참조 상세형은 표제어 기록을 기본으로 한다. 현상·법칙·개별 능력·분류표·표준은 별도 시작형을 선택한다.
- 문자 체계는 언어와 독립 문서로 생성할 수 있다. 언어 문서는 여러 문자·정서법을 연결할 수 있다.

## 실제 내용 작성

`{작성}`을 사실로 채우거나 상태 표현으로 교체한다. 필요한 곳에 실제 문서 링크를 넣는다. 일반 설명을 추가하기 위해 모든 표 셀을 채울 필요는 없다. 장문은 표 밖의 문단으로 쓴다. 미입력 수치에는 0을 넣지 않는다.

`기준시점`은 작중 시점이다. 기준시점이 없으면 `현재`라는 표현을 쓰지 않는다. `최초작성일`·`최종수정일`은 Templater가 실행되는 기기의 현실 시각이며 본문을 읽는다고 갱신되지 않는다.

새 조합기의 `values` 옵션은 `연속성`, `적용범위`, `기준시점` 등 공통 생성기가 허용하는 값만 전달한다. 고정 분류·템플릿 식별값과 잠긴 상태·버전은 덮어쓸 수 없다. B루트 경로에서 새 문서를 생성할 경우 기존 공통 생성기의 규칙에 따라 `연속성: [B루트]`를 명시해야 한다. 이를 자동 추정하지 않는다. 필요하면 해당 시작형 호출에 다음처럼 문서별 값을 전달한다.

```javascript
tR += await tp.user.render_extension_v21(tp, {
  preset: "X21-02-core",
  values: { "연속성": ["B루트"], "기준시점": "미정" }
});
```

이 예시는 원본 시작형의 호출을 이해하기 위한 것이다. 이미 작성한 문서에 실행 코드로 붙이지 않는다. 기존 문서를 새 템플릿에 이관하는 작업은 이 패키지의 범위가 아니다.

## 공개 전 확인

생성 문서는 기본 `draft: true`다. 이 값 자체가 모든 게시 도구에서 접근 통제를 보장하지 않는다. 게시 대상·Quartz 필터·참조 폴더 제외를 실제 빌드에서 확인한다. 작성·검토 메모, 생성 예시, 원문 참조, 검증 파일은 공개 본문과 분리해 취급한다. DataviewJS 버튼과 자동 상태 변경은 이번 확장에 넣지 않았다.
