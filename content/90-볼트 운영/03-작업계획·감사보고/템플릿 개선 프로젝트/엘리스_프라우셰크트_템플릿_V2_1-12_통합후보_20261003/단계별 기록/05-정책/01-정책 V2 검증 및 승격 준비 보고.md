# 정책 V2 검증 및 승격 준비 보고

<font style="font-weight:bold">진행 단계 5/12 · 정책 V2 · 작성일 2026-10-02</font>

정책 V2 핵심형과 상세형을 만들고 격리 자동검증을 완료했다. 템플릿 버전은 `2.0.0-rc.1`이다. <font style="font-weight:bold">격리 후보본 제작 완료, 실사용 승격은 HOLD</font>다. 사용자 지시에 따라 기관 다음의 정책 단계만 수행했다. 앞 단계의 실제 앱·게시 검증이 완료된 것으로 처리하지 않았다.

## 계승한 기준

기존 실사용 `08-국가 정책 템플릿.md`는 버전 0.1.2이며 범용 골격이다. 계획서 16절은 정책 정의·문제·단중장기 목표·수단·집행·재정·평가·법제 연결을 갖춘 전용 구조를 요구한다. 해당 절은 기준 폴더와 기존 Local Work 계승본의 내용이 같았다.

요청한 C 드라이브 기준 경로는 현재 호스트에서 확인되지 않아, 앞 단계와 같은 `E:\구글 드라이브\세계관\90-볼트 운영\03-작업계획·감사보고\템플릿 개선 프로젝트`의 하위 기준 파일을 읽었다. 이번 단계에서 Drive의 최신 revision을 별도로 비교하지 않았다.

기준 폴더의 공통 설계안과 계승본 사이의 속성 표기 차이는 기관 단계에서 확인한 상태로 남아 있다. 사용자가 기존 ZIP의 공통 SSOT와 생성기를 우선 계승하도록 지정했으므로 `aliases`·`tags`, 복원 호환값, 연속성·공개주소 보존을 갖춘 계승본을 유지했다. 기준 폴더 원본을 수정하거나 다른 공통 양식을 추가하지 않았다.

공통 `00-yaml 속성탭.md`와 `render_frontmatter.js`는 앞선 후보와 바이트가 같다. 공통 속성 32개·선택 속성 11개, B루트·복원·기존 내용 보호 규칙은 변경하지 않았다.

## 승격 준비 상태

후보는 `final/vault/`의 11개 파일이다. 공통 의존성 2개와 정책 전용 자산 9개로 구성된다. 별도 `sandbox-vault/`에는 후보·Templater·Dataview·빈 시험 노트 두 개를 준비했고 자동 생성 규칙과 시스템 명령을 껐다. ZIP에는 타사 플러그인과 사용자 설정을 넣지 않는다.
