# 국가 V2 격리 시험 및 승격 절차

자동검증 이후 실제 앱과 게시 환경에서 확인할 절차다. 아래 실환경 시험은 아직 완료하지 않았다.

## 별도 볼트 준비

이 작업 폴더의 `sandbox-vault/`를 Obsidian의 별도 볼트로 연다. 후보 파일, 로컬 설치본에서 복사한 Templater·Dataview, 빈 핵심형·상세형 시험 노트를 준비했다. 자동 생성 규칙과 시스템 명령은 껐다. 실제 병합표·스타일 표시는 기존 테마·CSS·표 표시 환경을 별도 볼트에 준비한 뒤 확인한다.

ZIP만 받은 경우 `vault/`를 별도 볼트로 열고 필요한 플러그인을 준비한다. 다음 경로를 <font style="font-weight:bold">격리 볼트 안에서만</font> 설정한다.

- Template folder: `90-볼트 운영/00-템플릿`
- User Script Folder: `90-볼트 운영/00-템플릿/유저 스크립트`

지역 정의·기관·정책 등 기존 설정 문서는 패키지에 동봉하지 않았다. 링크 해석은 읽기 전용 사본을 준비하거나 승격 시험에서 확인한다. ZIP의 생성 예시는 가상 제목과 고정된 시험 시각을 사용한다.

## 연속성과 복원 시험

격리용 시작형 사본에서 `values`로 문서별 값을 전달한다. 공통 원본의 기본값은 바꾸지 않는다.

```javascript
tR += await tp.user.render_nation(tp, {
  preset: "detailed",
  values: {
    "연속성": ["B루트"],
    "적용범위": ["신계", "라리셴베르크"],
    "기준시점": "시험용 세계관 시점"
  }
});
```

B루트 경로에서 연속성을 생략하면 거부하고 명시하면 생성되는지 확인한다. 복원 시험은 `기원상태: restored`와 확인된 복원 출처를 지정해 `복원여부: true`와 출처가 보존되는지 확인한다. 시험값은 정본 설정을 확정하지 않는다.

## 실사용 승격

1. 작업 패키지 전체가 게시용 동기화·Quartz 출력에서 제외되는지 확인한다. 참고표·보고서·구성요소에는 개별 draft 값이 없을 수 있다.
2. 별도 Quartz 사본에서 draft 제외, aliases·permalink, 기존 주소와의 충돌, 템플릿 참고 링크와 작업 메모 노출을 확인한다.
3. 현재 공통 원본·생성기·국가 V1을 백업하고 후보 매니페스트의 13개 파일과 실제 대상을 대조한다. 공통 두 파일이 앞 단계와 같으면 중복 원본을 추가하지 않는다.
4. 검증 결과와 교체 범위를 확인한 뒤 승격한다. 최초에는 국가 V1을 유지하면서 V2 시작형을 별도로 추가한다. 기존 국가 문서의 일괄 이관·V1 폐기·이름 변경은 별도 작업이다.
5. 문제가 있으면 추가한 국가 V2 자산을 되돌린다. 공통 의존성을 교체했다면 함께 백업으로 복구한다. 기존 생성 문서를 자동 삭제하지 않는다.

## 자동검사 재현

Node.js와 Python의 PyYAML을 준비해 패키지 루트에서 `node 검증/test_nation.js`를 실행한다. 실제 파서는 `TEMPLATER_BUNDLE` 환경변수에 설치된 Templater 2.13.1의 `main.js`를 지정하고 `node 검증/test_nation.js --engine`으로 검사한다. 번들 구조가 바뀌면 검사 어댑터를 검토한다.

검사에는 운영 볼트 API 대신 모의 Vault·편집기·YAML API를 사용한다. JSON에 기록된 실행 환경과 파서 해시를 결과와 함께 보관한다. 실제 앱 시험·공개 빌드를 대체하는 검사는 아니다.
