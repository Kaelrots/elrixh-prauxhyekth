# 6/12 역사 V2 — 검증 및 승격 준비

상태: 격리 후보본 제작·자동검증 완료. 실사용 승격 보류(HOLD).

일반·제1기 간략·복붙용 세 원본을 공통 사건 Core와 선택 상세 장으로 통합했다. 세 시작형이 한 본문을 공유한다. 신규 사건은 event / historical_event로 분류한다.

기존 reference 역사 문서는 변경하지 않았다. 제1기형의 중첩 actors/reliability·검색어 의미는 읽기 쉬운 본문 표에 계승했다. 실제 문서를 이관할 때는 기존 중첩 자료를 원형 보존해야 하며 이 작업은 이관을 수행하지 않았다. 신뢰도 점수 0, 특정 원문 이름과 과거 날짜를 새 문서의 사실로 자동 채우지 않는다. 누락된 본문 앵커 대신 모든 시작형에 실제 본문 서술 구획을 제공한다.

## 구성

- 02-역사 설정 템플릿 V2: 사건 Core와 참고·관리. 자료 신뢰성과 사건 전개 장은 필요할 때 추가한다.
- 02-역사 설정 템플릿 V2 상세형: 사료·신뢰성·전개·영향을 함께 기록한다. 빈 수치·신뢰도는 미입력으로 남긴다.
- 02-역사 설정 템플릿 V2 제1기 간략: 제1기 사건의 사료 소실·전승·복원 근거를 확인한다. 과거 meta_level L1은 간략 작성층위이며 정본 등급이 아니다. 제1기라는 이유로 기원상태를 restored로 바꾸지 않는다.

## 검증

- Node 모의 검사 64건, 실제 Templater 2.13.1 WASM 파서 검사 64건, 정적·계승 검사 70건. 실패 0건.
- 실제 파서 시험도 Vault·편집기·YAML API는 모의 환경이다. Obsidian GUI 시험이나 Quartz 전체 빌드를 수행한 것으로 간주하지 않는다.
- 참조 원본 해시 전후 일치. 공통 SSOT와 render_frontmatter.js는 선행 단계와 바이트 단위로 동일하다.
- `검증/생성예시`는 고정 시각·가상 제목을 사용하는 검증 자료이며 정본 설정이 아니다.

## 승격 전 남은 확인

1. 실제 볼트의 별도 복사본에서 빈 노트에 시작형을 삽입하고 병합표·HTML·Dataview 버튼을 확인한다.
2. Quartz에서 HTML·병합표·링크 표시를 확인하고 작업계획·검증 폴더의 공개 제외를 별도로 확인한다. `draft`나 `only-local`만으로 폴더 전체가 제외되지는 않는다.
3. 원본 백업과 차이 검토 후 승격한다. 00-템플릿 원본과 법령계 파일은 이번 단계에서 변경하지 않았다.

## 기준 자료 처리

기준 폴더 계획과 계승된 공통 SSOT의 충돌은 사용자가 우선 지정한 SSOT에 맞췄다. aliases·tags·복원여부 호환값·B루트 검증을 유지했다. 구식 공통 설계의 키 이름으로 되돌리지 않았다.
