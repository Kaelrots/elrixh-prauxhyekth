# 11/12 기술·연구 V2 — 검증 및 승격 준비

상태: 격리 후보본 제작·자동검증 완료. 실사용 승격 보류(HOLD).

기술 계열 5개 원본을 운영 허브(rule)·시대 인덱스(index)·게이트(entity)·관계 원장(ledger)·상세 기술(reference)로 정리했다. 6개 시작형이 공통 Frontmatter를 사용하며 doc_type과 기술 전용 키를 보존한다.

계획서 18~22절과 실제 기술 표준 사전을 대조했다. 규칙 링크는 존재하는 표준 문서 경로로 수정했다. 원장에 edge_id·valid_era를 추가하면서 from_gate/to_gate와 근거 source 열을 유지했다. 기존 조회식과 전체 추출기 호환은 아직 승인되지 않았다. 기존 gate 스키마의 중첩 prereq만 기술 조합기에서 별도 검증 후 덧붙여 평면 공통 생성기를 변경하지 않았다. 기존 중첩 데이터를 평면 대체키로 손실 변환하지 않으며 실문서 이관은 수행하지 않았다. 신규 ID·성숙도·시대·운영 상태를 예시로 자동 확정하지 않는다.

## 구성

- 10-기술·연구 테크트리 템플릿 V2: 규칙·ID·관계 운영의 허브다. 하위 템플릿 전문은 각 시작형에서 관리한다.
- 10_01_시대 인덱스 템플릿 V2: 시대별 발급대장과 코어·후보 목록을 얇게 관리한다.
- 10_02_게이트 노드 템플릿 V2: 한 게이트의 정의·근거·연계를 적는다. 관계의 기준은 엣지 원장이다.
- 10_03_엣지 레지스트리 템플릿 V2: 관계를 행 단위로 기록한다. status·ID·유효 시대를 확인한다.
- 10_04_상세 기술 템플릿 V2: 일반 기술의 원리·구현·스펙을 작성한다. 응용·파급 장은 선택한다.
- 10_04_상세 기술 템플릿 V2 확장형: 핵심 기술의 상세 백과형이다. 군사·차원·규제·게임 요소는 해당할 때만 작성한다.

## 검증

- Node 모의 검사 112건, 실제 Templater 2.13.1 WASM 파서 검사 112건, 정적·계승 검사 175건. 실패 0건.
- 실제 파서 시험도 Vault·편집기·YAML API는 모의 환경이다. Obsidian GUI 시험이나 Quartz 전체 빌드를 수행한 것으로 간주하지 않는다.
- 참조 원본 해시 전후 일치. 공통 SSOT와 render_frontmatter.js는 선행 단계와 바이트 단위로 동일하다.
- `검증/생성예시`는 고정 시각·가상 제목을 사용하는 검증 자료이며 정본 설정이 아니다.

## 승격 전 남은 확인

1. 실제 볼트의 별도 복사본에서 빈 노트에 시작형을 삽입하고 병합표·HTML·Dataview 버튼을 확인한다.
2. Quartz에서 HTML·병합표·링크 표시를 확인하고 작업계획·검증 폴더의 공개 제외를 별도로 확인한다. `draft`나 `only-local`만으로 폴더 전체가 제외되지는 않는다.
3. 원본 백업과 차이 검토 후 승격한다. 00-템플릿 원본과 법령계 파일은 이번 단계에서 변경하지 않았다.

## 기준 자료 처리

기준 폴더 계획과 계승된 공통 SSOT의 충돌은 사용자가 우선 지정한 SSOT에 맞췄다. aliases·tags·복원여부 호환값·B루트 검증을 유지했다. 구식 공통 설계의 키 이름으로 되돌리지 않았다.
