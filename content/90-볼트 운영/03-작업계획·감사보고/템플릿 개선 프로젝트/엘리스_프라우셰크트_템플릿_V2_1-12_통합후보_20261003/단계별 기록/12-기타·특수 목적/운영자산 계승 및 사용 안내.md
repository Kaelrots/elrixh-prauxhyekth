기존 Templater의 User Script Folder는 `90-볼트 운영/00-템플릿/유저 스크립트`로 확인했다. V1의 `time_update` 호출도 남아 있으므로 기존 파일을 이동하거나 덮어쓰지 않았다. V2 본문은 해당 구식 날짜 함수에 의존하지 않는다.

`time_update.js`는 활성 파일·원문 치환 방식, `update_dates.js`는 MetaEdit 의존 방식이다. 기존 파일은 계승참고에 원문 보존했고 이번 배포 대상에 포함하지 않았다. 두 파일을 삭제하면 기존 V1 문서의 버튼이 끊길 수 있다.

`mdToHtmlTable.js`와 `htmlToMdTable.js`는 단순 표 변환 방식이며 `<`·`^` 병합이나 HTML 장식의 무손실 왕복을 보장하지 않는다. V2 병합표를 일괄 변환하는 데 사용하지 않았다. `insertTagsToBottom.js`도 기존 실행 자산으로 유지하며 V2 공통 tags를 본문에 자동 중복 삽입하지 않는다.

새 특수 목적 폴더는 격리 후보본 안에서만 구성했다. 실사용 폴더 이동·Templater 설정 변경·자동 실행 활성화는 수행하지 않았다. 실제 아이콘 이미지·내부 링크·CSS·병합표·Dataview 표시는 Obsidian 복사 볼트에서 확인해야 한다.
