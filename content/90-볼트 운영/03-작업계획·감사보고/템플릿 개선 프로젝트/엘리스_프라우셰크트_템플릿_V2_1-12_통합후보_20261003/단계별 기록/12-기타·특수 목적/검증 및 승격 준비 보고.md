# 12/12 기타·특수 목적 V2 — 검증 및 승격 준비

상태: 격리 후보본 제작·자동검증 완료. 실사용 승격 보류(HOLD).

범용 기본형은 최소 7구획과 짧은 관리 안내로 만들고, 피드백은 별도 특수 목적 폴더의 운영 문서로 분리했다. 편집 앵커·수정일·복원 안내와 시각 조각의 V2 후보를 추가했다.

계획서 24·26·27절과 운영자산 원칙을 적용했다. 기존 피드백의 채워진 세계관 설명은 배포용 양식에 복제하지 않고 패키지의 계승참고에 원문 그대로 보존했다. 기존 User Script Folder 설정과 V1 호출을 확인했으므로 기존 실행 자산을 이동·덮어쓰지 않았다. 새 시작형은 80-특수 목적 템플릿에서 사용한다. 원본 지원 스크립트 5종은 현행 유지이며 무손실 표 변환기 개선은 이 제작 단계의 산출물에 포함하지 않는다. 날짜 버튼은 표시 중인 V2 문서의 최종수정일만 클릭 시 갱신한다.

## 구성

- 90-기타 문서 기본 템플릿 V2: 다른 전용 템플릿에 맞지 않는 문서의 최소 기본형이다. 특수 필드는 추가하지 않는다.
- 80-특수 목적 템플릿/세계관 피드백 양식 V2: 의견을 수집하는 운영 문서다. 범위·질문·받은 의견·반영 결정을 기록한다. 자동 제출이나 공유 기능은 없다.

## 검증

- Node 모의 검사 53건, 실제 Templater 2.13.1 WASM 파서 검사 53건, 정적·계승 검사 70건. 실패 0건.
- 실제 파서 시험도 Vault·편집기·YAML API는 모의 환경이다. Obsidian GUI 시험이나 Quartz 전체 빌드를 수행한 것으로 간주하지 않는다.
- 참조 원본 해시 전후 일치. 공통 SSOT와 render_frontmatter.js는 선행 단계와 바이트 단위로 동일하다.
- `검증/생성예시`는 고정 시각·가상 제목을 사용하는 검증 자료이며 정본 설정이 아니다.

## 승격 전 남은 확인

1. 실제 볼트의 별도 복사본에서 빈 노트에 시작형을 삽입하고 병합표·HTML·Dataview 버튼을 확인한다.
2. Quartz에서 HTML·병합표·링크 표시를 확인하고 작업계획·검증 폴더의 공개 제외를 별도로 확인한다. `draft`나 `only-local`만으로 폴더 전체가 제외되지는 않는다.
3. 원본 백업과 차이 검토 후 승격한다. 00-템플릿 원본과 법령계 파일은 이번 단계에서 변경하지 않았다.

## 기준 자료 처리

기준 폴더 계획과 계승된 공통 SSOT의 충돌은 사용자가 우선 지정한 SSOT에 맞췄다. aliases·tags·복원여부 호환값·B루트 검증을 유지했다. 구식 공통 설계의 키 이름으로 되돌리지 않았다.
