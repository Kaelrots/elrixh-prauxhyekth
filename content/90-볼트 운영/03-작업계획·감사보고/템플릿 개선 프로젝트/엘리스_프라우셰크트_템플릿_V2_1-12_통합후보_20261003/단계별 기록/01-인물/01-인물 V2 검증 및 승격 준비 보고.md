# 인물 V2 검증 및 승격 준비 보고

<font style="font-weight:bold">진행 단계 1/12 · 인물 V2 확정 · 작성일 2026-10-02</font>

인물 V2의 격리 최종후보 제작과 자동검증을 완료했다. 상세형과 빠른 시작형은 `2.0.0-rc.1`, 공통 Frontmatter 규격은 `2.0.0`이다. <font style="font-weight:bold">실사용 승격 판정은 HOLD</font>다. 실제 Obsidian 화면 시험과 작업폴더 공개 제외 확인이 남아 있으므로, 1/12 전체를 실사용 완료로 선언하거나 2/12 지역 제작을 시작하지 않는다.

## 기준과 계승

기준 경로는 사용자가 지정한 `세계관/90-볼트 운영/03-작업계획·감사보고/템플릿 개선 프로젝트`다. 현재 호스트에는 `C:\구글 드라이브`가 없고, `E:\구글 드라이브`의 대응 폴더가 있다. 로컬 폴더에는 최신 ZIP과 계획서가 없어 [Drive 정본 프로젝트](https://drive.google.com/drive/folders/1N_c6g8Ykj-B6HBpB8VyR8cUaAPhWBbMj)에서 원본을 받았다. 상위 폴더도 `03-작업계획·감사보고 → 90-볼트 운영 → 세계관`으로 확인했다.

직접 계승한 파일은 [frontmatter_v2_single_source_20261002.zip](https://drive.google.com/file/d/1azmJIcbZL_4rvUqQAggQawKaLDXn5npc/view)이다. Drive의 기준문서 두 개는 ZIP에 기록된 원본 해시와 일치한다. ZIP의 개정 기준문서는 내용 수정 없이 최종 패키지의 `기준문서/`에 계승했다. Drive의 기존 기준문서는 덮어쓰지 않았다.

다른 대화에 pilot.3 별도 ZIP의 제작 기록도 있었으나, 이번 요청이 지정한 단일원본 ZIP의 실제 파일을 우선 기준으로 삼았다. pilot.3의 실파일을 검증하거나 병합했다고 주장하지 않는다.

생성기는 여전히 문자열만 반환한다. 공통 YAML 양식이나 기본값을 JS·개별 템플릿에 추가로 복제하지 않았다. 신규 문서의 `draft`, 정본·작성·검토 상태, 날짜, 버전은 공통 원본 규칙을 따른다. 기존 문서의 자동 이관이나 버전 일괄 갱신은 구현하지 않았다.

71건 두 묶음은 동일 시나리오를 다른 실행 방식에서 확인한 것이다. 서로 다른 142개 사례로 집계하지 않는다. PyYAML은 6.0.3을 사용했으며 Obsidian의 실제 YAML API와 동일 구현이라고 보지 않는다.

검사 결과와 재현 코드는 `검증/`에 있다. 생성 예시는 가상 시험 제목과 `{작성}` 상태로만 만들었으며 실제 세계관 인물 설정을 새로 확정하지 않았다. 초기 검증 도구 설치 권한 문제는 다운로드한 패키지를 격리 폴더에 다시 풀어 해결한 뒤 재실행했다. 최종 집계는 완료된 실행만 반영한다.

## 실제 환경에서 확인한 사항

Templater의 `templates_folder`는 `90-볼트 운영/00-템플릿`, `user_scripts_folder`는 `90-볼트 운영/00-템플릿/유저 스크립트`다. 설치 버전은 2.13.1이다. 설정을 변경하지 않았다.

로컬 Quartz는 `RemoveDrafts`와 `AliasRedirects`를 사용한다. 소스상 `draft: true` 또는 문자열 `true`를 제외하고, `aliases`와 `permalink`를 리디렉션 목록에 반영한다. 이는 소스 검사이며 실제 공개주소 보존과 배포 성공을 입증하는 빌드 시험은 아니다.

현재 `ignorePatterns`에는 `90-볼트 운영/00-템플릿/**`가 있으나 프로젝트가 놓이는 <font style="font-weight:bold">작업계획 폴더 전체의 제외 규칙은 없다.</font> 게시 동기화 단계에서 제외할 가능성은 아직 검증하지 못했다. 보고서와 기준문서는 `draft`가 없을 수 있으므로, 작업 패키지를 볼트로 옮길 때 폴더 단위 비공개를 확인해야 한다. 접힌 callout과 `only-local` 클래스도 공개 제외 수단으로 간주하지 않는다.

원본 인물 V1, 원본 Frontmatter V1, Templater 설정·버전 파일, Quartz 설정 및 관련 처리기 등 8개 파일의 작업 전후 해시가 일치한다. 실사용 `00-템플릿` 교체, 기존 인물 이관, 법령계 편집, Quartz 배포는 수행하지 않았다.
