표의 모의/실제 파서 건수는 대체로 같은 시나리오를 두 환경에서 실행한 횟수이며 서로 다른 요구사항 수를 뜻하지 않는다. 모든 기재 검사는 실패 0건이다. 인물의 기존 51건 회귀검증, 기술 관계 검사 20건, 운영 조각 검사 15건도 별도 통과했다.

## 통합 검증

- 합쳐진 배포 폴더에서 시작형 30개를 실제 Templater 2.13.1 WASM 파서로 다시 생성했다. 모두 YAML 하나와 올바른 분류·초안 상태를 생성하고 파일에 직접 쓰지 않았다.
- 배포 파일 해시·공통 단일 배치·지원 함수·법령계 제외·원본 보존 등 통합 정적 검사 245건을 통과했다.
- 읽기 대조한 실사용 참조 파일 49개는 관측 당시와 최종 해시가 같다. 지정된 C: 경로에 해당하는 자료는 이 환경의 실제 E: 볼트에서 읽었고, 산출물은 C: 로컬 작업공간에 격리했다.
- Common SSOT는 aliases·tags·복원여부 호환·B루트 확인을 유지한다. 기준 폴더의 구식 공통 설계와 충돌할 때 사용자가 우선 계승하도록 지정한 산출물의 규격을 적용했다.
- 기존 `<`·`^` 병합, span·center·br·hr 클래스 문법을 유지했다. 각 종류에 필요한 표의 의미를 보존하면서 Core와 선택 상세 영역을 구분했다.

실제 파서 시험에서도 Vault·편집기·YAML API는 모의 환경이다. Obsidian의 최종 화면·플러그인 간 상호작용이나 Quartz 전체 빌드를 검증한 결과가 아니다.

## 주요 계승 결정

역사의 제1기 간략형은 일반 사건 Core를 공유한다. 특정 과거 원문·날짜·신뢰도 0을 새 문서에 자동 입력하지 않는다. 정치·사상과 종교는 주장·실제 제도·신앙·확인된 사실을 구별한다. 종족은 공통 Frontmatter를 추가하고 종족·문화·국적과 개체차를 구별한다.

자원은 마학·연방 통제·영혼 마모를 선택 장으로 두었다. 기존 척도·정제 단계는 참고 모델로 보존했으며 값이 없다고 최저 위험·안전·0으로 판단하지 않는다. resource_id는 확인된 식별자만 기록한다.

기술 계열은 실제 표준 사전을 우선했다. doc_type·gate_id와 기존 기술 전용 키를 보존하고, 중첩 prereq.hard/soft만 기술 조합기에서 유형 검사를 거쳐 생성한다. 공통 생성기의 평면 확장 계약은 변경하지 않았다. 관계 원장의 from_gate/to_gate와 근거 source 열을 유지하면서 edge_id·valid_era를 추가했다. 유효 시대의 자연어 해석과 기존 전체 추출기의 호환성은 별도 검토 대상이다.

피드백은 운영용 양식으로 분리했다. V1의 채워진 세계관 설명은 별도 원문 보존본에 남기고 새 요청에 자동 복사하지 않는다. 기존 지원 스크립트 5종과 호출 경로는 그대로 두었다. 원문 보존본은 새 배포용 템플릿이나 최신 정본 설정이 아니다.

## 승격 상태: HOLD

요청한 격리 후보본과 검증·승격 준비 자료는 완성했다. 실사용 승격은 다음 확인이 남아 있다.

1. 복사 볼트에서 시작형 삽입, 병합표·HTML·이미지·내부 링크·Dataview 버튼을 실제 화면으로 확인한다.
2. Quartz 복사 환경에서 생성 문서의 표·HTML·링크를 빌드한다. 작업계획·검증·원문 참고본 폴더의 공개 제외도 확인한다. 현재 확인한 Quartz 설정의 00-템플릿 제외만으로 프로젝트 작업 폴더 전체가 제외되지는 않는다.
3. V1/V2 공존과 기존 쿼리·추출기·Templater 경로를 확인한 뒤 백업·차이 검토를 거쳐 승격한다. 공통 원본은 기존 파일명과 같으므로 자동 덮어쓰지 않는다.

이번 통합 후보본에는 법률·황제령·헌법 템플릿의 제작·변경을 포함하지 않았다. 관련 문서로의 참조는 각 설정의 맥락을 보존하기 위해 남겨 두었다.
