# 국가 V2 사용 안내

<font style="font-weight:bold">3/12 국가 V2 · 2026-10-02 · 템플릿 2.0.0-rc.1 · 공통 스키마 2.0.0</font>

국가 문서의 핵심 정체성과 관련 문서 허브를 먼저 작성하는 격리 후보본이다. 국호·한 줄 국가상·국가 존재 이유부터 시작하고 필요한 상세 장만 추가한다. 기존 실사용 템플릿에는 아직 반영하지 않았다.

빈 새 노트에서 Templater의 삽입 명령으로 시작형 하나를 선택한다. `국가 V2 구성요소/`는 본문 원본, `국가 V2 참고표/`는 선택지 참고 자료다. 이 파일들을 시작형 대신 전체 삽입하지 않는다. 기존 문서에는 템플릿을 재실행하지 않고 필요한 본문 구획만 복사한다.

두 시작형은 `render_nation.js`를 통해 같은 본문 원본 7개를 사용한다. Core나 선택 장의 수정은 이후 생성 문서에 반영되며 이미 작성한 문서는 자동 변경하지 않는다. 핵심형은 205줄, 모든 선택 장을 담은 상세형은 538줄이다. 공통 YAML과 문서 관리용 코드도 포함한 시험 출력의 줄 수다.

## 설치 단위와 공통 원본

`vault/90-볼트 운영/00-템플릿/` 아래 13개 파일이 한 설치 단위다.

- 앞 단계에서 그대로 계승한 공통 Frontmatter와 `render_frontmatter.js` 2개
- 국가 시작형 2개와 `render_nation.js` 1개
- 국가 본문 구성요소 7개
- 국가 V1 선택표 보존본 1개

한 볼트에서 공통 원본은 같은 경로의 한 파일로 운영한다. 인물·지역 패키지의 공통 의존성과 내용이 같으므로 중복 활성 원본을 만들지 않는다. 실사용 볼트에 남아 있는 V1 공통 파일의 교체는 승격 절차에 따라 판단한다.

## 작성 기준

기본 분류는 `entity + nation`, 분야는 `국가·정치`다. 문서 상태·날짜·공개 여부는 기존 공통 SSOT를 따른다. 기본 상태는 `draft / outline / unreviewed`, 공개 제어값은 `draft: true`다. 국가의 체제·영토·인구 등 실제 값은 자동 선택하지 않는다.

지리 5층위와 법정 행정구역, 영유권 주장과 실제 통제, 공공 이념과 민간 견해, 법적 제도와 실제 관행을 구별한다. 통계에는 범위·시점·단위·분모·근거를 붙인다. 국가는 각 분야의 요약과 대표 링크를 맡고, 기관·정책·법령·지역·역사의 상세 내용은 해당 문서에서 관리한다.

V1의 체제·이념·권리 선택표와 산업 구성표는 별도 보존본에 원문 그대로 남겼다. 국가 문서에 자동 삽입하지 않으며 선택지는 정본 설정을 확정하지 않는다. V1에서 미검토로 표시된 산업표는 그 출처 상태도 명시했다. 기존 예시 국가·민족·언어·인구·비율은 새 국가의 기본값에 넣지 않았다.

`<`·`^` 병합기호, span, center, br, hr 클래스는 유지했다. 작성 본문을 재구성했으므로 V1과 기호 개수가 같지는 않다. 보존 대상 선택표의 바이트 동일성은 별도로 확인했다.
