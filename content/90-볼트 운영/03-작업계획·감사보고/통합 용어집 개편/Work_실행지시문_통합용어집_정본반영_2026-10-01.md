## C. 초월자·신·제국도교

주요 대상:

- `초월자.md`
- 제국도교 교리의 초월신론·선지자·신 관련 문서
- 필요 시 관련 용어 풋노트·색인

### 반드시 일관화할 정의

#### 초월자
- 인간의 육신과 인간의 영혼을 유지함
- 격·위격·능력·존재 위상이 통상적 인간의 한계를 넘어섬
- 여전히 인간 존재양식에 속함

#### 신
- 초월자가 자기 격을 다시 초월
- 승천하여 인간 육신 의존을 벗어남
- 영혼 자체가 독립적 존재기반이 됨

#### 초월신
- 위 경로로 신이 된 존재를 가리키는 제국도교 신학 용어

#### 신앙
- 신의 존재를 성립시키는 보편적 필수조건이 아님
- 위격 안정·현현·영향력 등에 영향을 줄 수 있음

### 금지

다음은 확정하지 않는다.

- 집단신앙 자체가 별개의 신을 생성한다는 설정
- 개념·영역 자체가 다른 기원의 신을 생성한다는 설정
- 비인간 존재에게 인간과 동일한 초월→승천 경로가 적용된다는 설정

이들은 HOLD다.

### 제국도교 5단계

`일반인 → 수도자 → 선지자 → 초월자 → 신`

은 <font style="font-weight:bold">제국도교의 수행·교리 모형</font>으로 표현한다.
우주 전체에 강제되는 단일한 객관적 순서로 쓰지 않는다.

- 친화력·전도율의 보편적 반비례 법칙

- 성급별 정확한 수치

# 7. QA 필수항목

모든 수정 후 다음을 검사한다.

1. 깨진 위키링크 없음
2. 잘못된 anchor 없음
3. 중복 표제어 없음
4. aliases 충돌 없음
5. 공통 용어와 전문사전 정의가 서로 모순되지 않음
6. D/P/국소충돌 결정이 누락되지 않음
7. HOLD가 정본으로 승격되지 않음
8. B루트가 A루트에 혼입되지 않음
9. 구식 헌정 설명이 현행 헌법보다 우선하지 않음
10. 복원 마법 문서의 미확정 수치가 정본화되지 않음
11. `차원인정` 오탈자 잔존 여부 검사
12. `전이계`가 제4차원으로 남은 곳 검사
13. `혼류=차원류 전체`로 오독되는 문장 검사
14. `7성급=초월자` 식 등치 검사
15. `신앙 필수=신 존재` 절대명제 잔존 검사
16. `엘룬=언어` 또는 `엘루닉어=문자` 역전 표기 검사
17. 기존 28개 통합용어 링크 호환성 검사

# 8. 완료 보고 형식

Work는 완료 후 반드시 다음을 보고한다.

## 8.1 변경 파일 목록

각 파일마다:

- 파일명
- Drive ID
- 이전 경로 / 현재 경로
- 정본상태
- 수정 유형
- 핵심 변경사항
- 근거 결정 ID

## 8.2 신규 파일

신설한 전문사전·index가 있으면:
- 생성 이유
- 기존 파일로 대체할 수 없었던 이유
- 역할
- 연결된 원문 목록

## 8.3 HOLD

반영하지 않은 항목을 전부 목록화하고,
왜 보류했는지 기록한다.

## 8.4 검증

- 링크 검사
- 용어 충돌 검사
- 정본상태 검사
- 별칭 검사
- 핵심 문자열 검색 결과
- 수정 전후 diff 요약

## 8.5 최종 판정

다음 중 하나로 끝낸다.

- `PASS — 전체 반영 및 QA 완료`
- `PASS WITH HOLD — 확정 범위 반영 완료, HOLD는 미반영`
- `BLOCKED — 정본 식별 또는 충돌 때문에 사용자 판단 필요`

사용자가 이미 07에서 확정한 문제를 다시 질문하지 않는다.
새로운 진짜 충돌이 발견된 경우에만 BLOCKED 항목으로 보고한다.

# 9. 절대 금지

- 07 결정을 임의 재설계
- HOLD를 추론으로 채움
- 과거 복원문서 전체를 최신 정본으로 승격
- 보존용·구식 문서 수정
- B루트를 A루트 정사로 병합
- 통합 용어집을 세부설정·수치 백과사전으로 비대화
- 동일 역할 전문사전을 이유 없이 중복 생성
- 실제 정본을 찾지 않고 파일명만 보고 무작정 수정
