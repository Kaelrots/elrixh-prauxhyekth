# 행성 지도 에디터 V2 — 인수검증·표본·실행 기록

작성일: 2026-10-02 · 버전: 2.0-draft.1  
상태: <font style="font-weight:bold">검사 설계. 아래 모든 신규 검사는 초기 상태 NOT_RUN이며, 테스트 코드가 제공되거나 통과했다는 뜻이 아니다.</font>

## 1. 사용 원칙

기존 앱 인수 기준, UI/UX 추가 검사, EXE 전환 C/P/R 검사를 대체하지 않는다. V2-00에서 현재 검사와의 대응을 만들어 재사용할 수 있는 테스트는 재사용하고 신규 동작만 추가한다. `PASS`에는 실행 명령·종료 코드·입력·소스·환경·결과 경로가 필요하다.

`BLOCKED_INPUT`과 `BLOCKED_ENVIRONMENT`는 실패를 숨기는 표기가 아니라 실제 차단 원인을 기록하는 상태다. 해당 필수 관문을 통과했다는 뜻은 아니다. 미래 버전이나 미지원 형식을 N/A로 바꾸어 편집 가능하다고 표시하지 않는다.

## 7. 통합 시나리오 — 첫 사용 경험

### 시나리오 A: 기존 프로젝트 편집 경로 보존

FX-BASE를 열고 알려진 좌표를 선택한다. 이름·인구·메모 중 현재 승인된 필드를 수정하고 실행 취소·다시 실행한다. 프로젝트 파일을 실제 기록한 다음 새 세션에서 열어 <font style="font-weight:bold">전체 의미값과 필수 자산</font>을 비교한다. 원본 식별색·미해결 소속·coverage가 손실되지 않아야 한다.

### 시나리오 B: MD를 권위 원본으로 쓰는 문서 연결

별도 FX-MD에 Region을 바인딩하고 관리 필드 하나를 수정한다. diff에서 본문·다른 메타가 변하지 않는 것을 확인한 후 승인 저장한다. 파일을 다시 읽고, 새 앱 세션에서 같은 문서와 Region을 연결하여 값을 확인한다. 사용자가 관리하지 않은 본문의 바이트 해시는 같아야 한다.

### 시나리오 C: JSON을 권위 원본으로 쓰는 별도 연결

FX-MD의 미러 파일이 아닌 별도 FX-JSON으로 같은 절차를 수행한다. 권위·캐시 역할을 명확히 하고, 관리 밖 필드와 숫자 의미를 보존한다. 한 문서에서 변경할 수 없는 형식은 사본 출력 또는 읽기 전용으로 표시한다.

### 시나리오 D: 충돌이 발생한 실제 저작 흐름

앱에서 문서를 읽고 값을 고친 뒤 디스크의 같은 문서를 외부에서 변경한다. 앱 저장은 충돌을 표시해야 한다. 취소/원문 재로드/사본 저장을 선택할 수 있어야 하고, 자동으로 어느 버전이 ‘정본’인지 정하지 않는다. 이미 저장한 뒤 Undo할 때도 같은 보호가 적용된다.

  "fixtureManifestHash": null,
