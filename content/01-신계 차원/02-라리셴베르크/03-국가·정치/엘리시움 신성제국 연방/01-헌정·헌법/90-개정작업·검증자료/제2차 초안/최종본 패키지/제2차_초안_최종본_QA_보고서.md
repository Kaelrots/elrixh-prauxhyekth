# 제2차 초안 최종본 QA 보고서

## 판정

<font style="font-weight:bold">요청한 별도 최종본 작성과 양식 편집은 완료하였다. R5-A1.16 대비 실질 조문 문언 변경은 0건이다. 다만 기준본 자체에서 승계한 비상권 조항 충돌 1건과 항번호 공백 1건이 있어, 무조건적인 정본 승격 통과 판정은 하지 않는다.</font>

기존 제1차 초안과 R5-A1.16 원본은 수정하지 않았다. 이번 최종본은 기존 정본 파일을 대체하거나 세계관 내 공포·시행을 완료한 문서가 아니다. 이전 채팅의 “새로운 충돌 없음” 및 정적 검증 보고를 그대로 인용하지 않고, 실제 기준본의 본문·번호·각주·링크를 새로 대조하였다.

본문 대조는 서문부터 설명각주 끝까지 수행하였다. 비교에서 제외·정규화한 것은 아래에 명시한 편집 코멘트, 출처 식별자, 빈 줄·구분선, 제목의 Markdown 단계, 절 제목의 HTML 표현, 중복된 빈 조문 제목 7개, 이미지 임베드 문법 및 제4장 제2조 제6항·제7항의 표시 순서뿐이다. 일반 문장, 수치, 의무·권한 표현, 위키링크 대상, 각주 정의와 호출은 임의로 정규화하지 않았다.

정규화한 전체 본문의 문자열과 SHA-256이 일치한다. 947개 조문도 각각 대조하였다. 기존 E-01~E-10의 61개 항목은 승인대조표가 지정한 근거조문의 문언 보존을 재확인하였다. 이는 해당 정책의 타당성이나 기준본의 무결성을 새로 61건 모두 승인했다는 뜻이 아니다.

## 양식 정비 내역

1. 제1차 초안과 동일한 YAML 필드 구조를 사용하고 문서명·수정일·버전·변경요약을 이번 결과에 맞췄다. 작성자·최초작성일·태그·템플릿 정보는 승계하였다.
2. 개요, 작성/수정일 영역, 기존 DataviewJS 버튼 코드 및 문서 계승 표의 구조를 보존하였다. 옛 작업기록 대신 이번 편집기록·QA 보고서를 연결하였다.
3. 중앙정렬된 국가명·헌법명·제정일 HTML 세 줄은 원문 그대로 유지하였다. 제3기 179년 제정일은 기존 역사적 제정일이다. 이번 개헌의 공포일·시행일은 생성하지 않았다.
4. 목차는 R5-A1.16의 21장으로 작성하였다. 본문은 장 `##`, 조 `###`, 항 `####`, 호 `#####`, 목 `######` 계층을 유지하고, 총강은 기존 양식대로 총강 `###`·조 `####`를 사용하였다. 절 제목 181개는 1차 초안의 중앙정렬 HTML 형식으로 표시하였다.
5. `[!summary]`, `[!info]`, `[!abstract]`의 실제 내용과 펼침·접힘 표시는 보존하였다. 승인 작업메모인 `[!success]` 1개만 편집기록으로 옮겼다.
6. `hr-thick-1~4` 구분선을 장·절·조 구분에 적용하였다. 기존 법문과 용어·문체는 다시 쓰지 않았다.
7. 기존 이미지 7회·6종은 `![[파일명.png]]` 문법으로 전환하였다. 첨부 조직도 14개를 원본 그대로 포함하였다. 나머지 8개를 새 조문에 임의 배치하거나 최신 법적 조직도로 인증하지 않았다.
8. HTML 작업 코멘트 1,944개와 본문에서 호출하지 않는 출처 앵커 962개를 분리하였다. 실제 상호참조에 필요한 앵커는 삭제하지 않고 대상 제목에 결합했다. 역사자료의 비규범성을 정한 제21장 제9조 제6항과 그 설명각주도 보존하였다.
9. 빈 중복 조문 제목 7곳은 바로 뒤의 개정된 제목과 통합하였다. 제4장 제2조의 항 표시 순서는 `1·2·3·4·5·7·6`에서 `1·2·3·4·5·6·7`로 정돈하였다. 항번호와 문장은 바꾸지 않았다.

## 정본 승격 전에 처리할 두 항목

### 1. 제14장 제16조의 옛 비상권 문장 잔존 — 내용 충돌

위치: [[엘리시움 연방 헌법_제2차 초안 최종본#^ren-c14-a0016|제14장 제16조]]. 기준본 추적번호 `SRC-C03-L01352-P05`.

새 제1항~제7항 뒤에 다음 문장이 다시 <font style="font-weight:bold">제2항</font>이라는 제목으로 남아 있다.

> 긴급황제령의 기본 일몰 기간은 14영업일로 한다. 연장이 필요한 경우 합동의회 재가를 받아야 한다. 사후추인 상정은 공고 후 72시간 이내 접수, 7영업일 이내 표결을 원칙으로 한다.

이 잔존문은 제15조의 <font style="font-weight:bold">14영업일과 30달력일 중 먼저 도래하는 최초 일몰</font>, 제16조 제1항의 <font style="font-weight:bold">최초 승인과 같은 기관·정족수에 의한 연장 의결 및 황제 재가·재발령</font>과 충돌하거나 오해를 일으킨다. 특히 “합동의회 재가”가 새 절차와 일치하지 않는다. 항번호 중복만 제8항으로 바꾸면 이 충돌은 해결되지 않는다.

<font style="font-weight:bold">교정 제안:</font> 이 옛 제2항 한 항을 삭제하고, 새 제1항~제7항을 유지한다. 삭제 대상의 원문은 비규범 편집기록에 보존한다. 이번 요청의 “R5-A1.16 실질변경 0건”을 준수하기 위해 최종본에는 아직 적용하지 않았다.

### 2. 제6장 제20조의 제4항 공백 — 번호 정비

위치: [[엘리시움 연방 헌법_제2차 초안 최종본#^ren-c06-a0020|제6장 제20조]]. 기준본의 항 배열은 `제1항·제2항·제3항·제5항`이다. 제4항 본문은 제공 기준본에 존재하지 않는다.

<font style="font-weight:bold">교정 제안:</font> 실제 문장 누락이라는 추가 근거가 없다면, 현 제5항(예산·재정분석 지원기구)을 제4항으로 번호만 정돈한다. 존재하지 않는 제4항의 내용을 새로 작성하지 않는다. 번호 변경 역시 기준본과의 완전한 추적성을 위해 이번 최종본에는 적용하지 않았다.

두 제안을 검토할 수 있도록 `검증자료/승격전_교정제안_미적용.diff`에 정확한 변경안을 넣었다. 해당 diff는 본문에 적용되지 않았다. 본문의 새 번호를 확정할 때에는 본문 밖 수용규범·연혁자료의 인용도 함께 확인해야 한다.

제16장 제62조의 “제1항; 단서”는 제1항 단서의 별도 표시이므로 독립된 중복 항으로 계산하지 않았다. 제21장의 여러 “부칙의 1” 등은 출처별 부칙 제목으로 보존하였다. 서로 다른 제목·앵커가 있으므로 문서 내부 이동은 가능하지만, 외부 인용에서는 장·제목 또는 앵커까지 적어야 한다.

## 렌더링과 외부 자료의 확인 범위

<font style="font-weight:bold">완료한 검사는 Markdown 구조와 생성된 HTML의 정적 검사이다. 실제 Obsidian/Quartz 앱 화면을 띄워 검증한 것은 아니다.</font> `양식_미리보기.html`은 표제·콜아웃·구분선·목차·이미지의 배치를 확인하기 위한 보조 파일이다. 7개 이미지 경로와 HTML 내부 링크 대상은 모두 존재한다. 사용자 Prism 테마, `hr-thick-*`의 실제 CSS, Dataview·Templater 동작 및 Quartz의 배포 설정은 로컬 볼트에서 확인해야 한다.

`연방 황실 직속 기관 조직도.png`는 기준본과 동일한 외부 그림의 텍스트 참조로 남겼다. 해당 파일은 제공되지 않았으므로 새 임베드나 가상의 조직도를 만들지 않았다. `템플릿 수정 기록#90-기타 문서 기본 템플릿`은 1차 양식의 외부 볼트 링크이며 대상 파일이 이번 패키지에 없으므로 링크 대상의 존재를 검증하지 않았다.

공포일·시행일(T0), 시행일 현재 재판관 명부·임기·인선주체는 미정이다. 첨부한 경과계획·교차임기 템플릿은 이전 파일 그대로 보존하였고, 실제 날짜·인명을 추가하지 않았다.
