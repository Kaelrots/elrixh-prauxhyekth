# 제2차 초안 최종본 패키지

`엘리시움 연방 헌법_제2차 초안 최종본.md`를 열어 검토하세요. 기존 정본을 덮어쓰지 않는 별도 파일입니다.

1. `제2차_초안_최종본_QA_보고서.md`에서 완료 범위와 기준본 승계 문제 2곳을 먼저 확인합니다.
2. Obsidian에서는 본문·QA·편집기록과 `assets` 폴더를 같은 볼트에 넣습니다. 이미지 위키링크는 원래 파일명을 사용합니다. 같은 이름의 다른 이미지가 이미 있다면 중복 파일을 만들기 전에 동일한 그림인지 확인하세요.
3. `양식_미리보기.html`은 압축을 푼 뒤 열면 됩니다. 실제 Obsidian/Quartz의 CSS와 플러그인 화면은 아닙니다.
4. `검증자료/승격전_교정제안_미적용.diff`는 검토용 제안이며 자동 적용되지 않습니다.

- `기준자료`: 내용 기준과 1차 양식 원본의 보존 사본.
- `경과자료`: 기존 A/B/C 계획과 최초 교차임기 템플릿. 날짜·인명 미입력 상태 유지.
- `검증자료`: 문언 대조·번호·링크·각주 검증 결과와 재실행용 Python 스크립트.
- `assets`: 제공받은 조직도 14종 원본.

정본 승격은 비상권 잔존문과 번호 문제를 정리한 뒤 진행합니다. 현 단계에서는 세계관 내 공포·시행이나 기존 정본 파일 교체가 이루어지지 않았습니다.
