# 《엘리스 프라우셰크트》 헌법 하위 법령 제정 작업 상세 계획서

## 1. 작업 목적

본 작업은 현행 「엘리시움 신성제국 연방 제2연방 헌법」에서 하위 규범으로 이관된 사항을 실제 연방 법률·연방 황제령·기관규칙·교구칙례 등의 형태로 구체화하는 것을 목적으로 한다.

현재 작성되어 있는 L-01~L-23 문서는 제정된 법령이 아니라 <font style="font-weight:bold">제정설계서</font>이므로, 이를 그대로 법으로 간주하지 않는다. 현행 헌법을 최상위 기준으로 두고, 이관 원문·제정설계서·기존 설정을 대조하면서 조문을 새로 구성한다.

본 계획에서는 기존 A/B/C 제정등급을 유지하되, 이를 실제 작성순서와 구별한다.

- <font style="font-weight:bold">제정등급</font>: 헌법 시행 후 실제 수용규범을 마련해야 하는 시간적 우선도
- <font style="font-weight:bold">작성순서</font>: 다른 법령을 안정적으로 작성하기 위해 먼저 확정되어야 하는 제도적 선행관계

따라서 A급 법령이라도 다른 조직법의 확정이 필요하면 후행 작성할 수 있으며, B급 법령이라도 다른 여러 법령의 기반이 되는 부분은 먼저 작성할 수 있다.

# 2. 기본 작업 원칙

## 2.1. 헌법 우선

현행 제2차 헌법에서 이미 확정한 다음 사항은 하위 법령 작성 과정에서 재논의하지 않는다.

- 헌정기관의 헌법상 지위
- 기관 간 기본 권능 배분
- 기본권 및 권리제한의 한계
- 주요 의결정족수
- 조약의 국내적 효력
- 황제의 헌법상 권능
- 의회의 헌법상 권능
- 사법심사의 기본구조
- 비상권의 헌법적 한계
- 그 밖에 헌법 본문에서 직접 확정한 사항

하위 법령은 이를 <font style="font-weight:bold">구체화·집행하기 위한 절차와 조직을 설계</font>하는 역할을 한다.

## 2.2. 이관 원문 보존

각 이관 원문은 다음 세 유형으로 구분한다.

1. <font style="font-weight:bold">직접 계승</font>
   - 정책적 판단이 이미 확정되어 있고 현행 헌법과 충돌하지 않는 내용

2. <font style="font-weight:bold">정합화 후 계승</font>
   - 기관명·절차·규범형식 등의 변경이 필요하지만 기본 취지는 유지하는 내용

3. <font style="font-weight:bold">재결정 필요</font>
   - 새로운 기관·수치·권리제한·제재·의무 등을 요구하거나 현행 체계와 충돌할 가능성이 있는 내용

원문의 삭제·변형은 반드시 이유를 기록한다.

## 2.3. 미확정 설정 보류

영혼·격·위격·각성·마법·신격·차원현상 등 현재 별도 설정 정합화가 진행 중인 개념에 의존하는 규정은 임의로 확정하지 않는다.

해당 부분은 다음과 같이 관리한다.

`[보류: 관련 개념 정의 확정 후 재검토]`

## 2.4. 순환의존 법령은 2회 작성

두 법령이 서로를 참조해야 하는 경우 한쪽을 억지로 먼저 완성하지 않는다.

- <font style="font-weight:bold">1차 작성:</font> 기관·권한·기본 절차와 인터페이스만 확정
- <font style="font-weight:bold">관련 법령 작성</font>
- <font style="font-weight:bold">2차 정비:</font> 세부 교차참조·기술기준·공동절차를 최종 반영

대표 사례는 다음과 같다.

- L-05 의회기본법 ↔ L-07 정부조직법
- L-03 헌법원법 ↔ L-04 법원조직법
- L-09 재정·예산법 ↔ L-08 준비 기금법
- L-18 조약·외교기본법 ↔ L-17 성간항행 법규
- L-14 제국도교 관계법 ↔ L-23 차원·성역 안전법

# 3. 각 법령 공통 작업 절차

각 L-법령은 원칙적으로 다음 순서로 처리한다.

### 1단계 — 헌법상 수권범위 추출

관련 헌법 조항에서 다음 사항을 정리한다.

- 헌법이 직접 정한 사항
- 법률에 위임한 사항
- 황제령에 위임한 사항
- 기관규칙 등에 재위임 가능한 사항
- 하위 규범으로도 변경할 수 없는 헌법적 한계

### 2단계 — 이관 원문 대응

### 3단계 — 선행 법령과의 인터페이스 확인

다음 요소를 확인한다.

- 담당기관
- 임명권자
- 의결기관
- 보고기관
- 감사기관
- 사법심사기관
- 공표 방식
- 개인정보·기밀 처리
- 예산·재정 절차
- 비상절차

### 4단계 — 쟁점별 논의

한 번에 법 전체를 확정하지 않는다.

서로 연관된 쟁점을 보통 <font style="font-weight:bold">2~5개 단위</font>로 제시하여 Chat에서 결정한다.

결정 결과는 누적하여 이후 조문 작성의 전제로 사용한다.

### 5단계 — 조문 초안

충분한 결정이 모인 장·절부터 실제 조문으로 전환한다.

이때 각 조문은 내부적으로 다음을 구분한다.

- 헌법 직접구체화
- 이관 원문 계승
- 정합화를 위한 수정
- 신규 보완사항

### 6단계 — 법령 내부 QA

- 권한 중복
- 기관명 불일치
- 수권 없는 기관규칙
- 권리제한 법률유보 위반
- 정족수 불일치
- 기한 충돌
- 다른 법령과의 중복
- 순환참조
- 정의어 불일치

등을 검사한다.

### 7단계 — 후행법 인터페이스 등록

해당 법령에서 후행 법령이 반드시 따라야 할 내용을 별도로 기록한다.

이를 <font style="font-weight:bold">법령 인터페이스 목록</font>으로 사용한다.

<font style="font-weight:bold">한 법령 선택 → 헌법 수권범위 확인 → 관련 이관원문 전수 추출 → 선행법 확인 → 쟁점 2~5개 논의 → 결정 누적 → 해당 장·절 조문화 → 내부 QA → 다음 쟁점</font>
